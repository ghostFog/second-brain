# 架构重构记录

> **本文件为项目架构/文档结构重构的历史记录（独立成文，2026-09-10 自 `doc/开发进度.md` 拆出）。**
> 用途：按时间倒序记录对项目架构、工程结构、文档结构做过的重要重构，便于追溯「为何是现在这个结构」。

- **2026-09-10（修复·Bug-039）**：解决「侧边面板-标签等元素加 `border-b`/`border-t`/`border-l`/`border-r` 不显示边框线」——Tailwind v4 browser 版方向性边界类只生成 `border-*-style: var(--tw-border-style)`，该变量不上 `border-solid` 类即未定义、回退 none。在 `css/base.css` 的 `:root` 全局默认 `--tw-border-style: solid`，使 `border-b/t/l/r` 单独即可显示实线，需虚线/点线再叠 `border-dashed/dotted`。回归新增 `testDefaultBorderStyle`，`npm test` 71 通过 0 失败。详见 `doc/历史Bug记录.md` Bug-039。

- **2026-09-10（修复·Bug-038）**：解决 vditor IR 模式「空行删不掉 & 块前 Backspace 不删上一空行」——vditor 原生对 `data-block="0"` 的 ZWSP 空段落 Backspace 只删文本节点、段落残留，块前 Backspace 也优先跳转而不删上方空行。新增捕获阶段 keydown 监听 `handleIrDeleteKeydown`（命中时 `preventDefault`+`stopImmediatePropagation`）：①`isEmptyLine` 判定空段落，Backspace/Delete 都 `removeEmptyLine` 删整行并定位光标到相邻块；②光标在块最前（`blockRootOf`+`caretAtBlockStart`）Backspace 且上一行是空行则删之，非空行放行给 vditor 跳上一行。回归新增 `testIrEmptyLineDelete`，`npm test` 70 通过 0 失败。详见 `doc/历史Bug记录.md` Bug-038。

- **2026-09-10（修复·Bug-035/Bug-036/Bug-037）**：解决 vditor 编辑器三个渲染问题——①有序列表序号丢失：Tailwind Preflight 重置 `ol` 样式且 vditor 未恢复，在 `css/app.css` 补充 `#ed-vditor` 容器作用域下 `ol{list-style-type:decimal}`；②表格/代码块前无法插入内容：新增 `irInsertAbove` 助手及右键菜单「在上方插入空行」入口，在带 `data-block="0"` 的块根前 `insertBefore` 插入空段落并用 `<wbr>` 锚定光标；③任务列表显示异常：以 Lute 序列化往返测试防退化。回归新增 `testIrBlockAbove`/`testOrderedListCss`/`testTaskListRoundTrip` 三断言，`npm test` 65 通过 0 失败。详见 `doc/历史Bug记录.md` Bug-035/036/037。

- **2026-09-08（修复·Bug-026）**：解决「打开软件编辑器正文空白」——vditor 首帧异步渲染时 `after` 回调用 `this.setValue` 取错上下文抛错，补渲失败。改为闭包捕获实例引用 `inst||vdInst` 调 `setValue`；移除 `main.js` 临时 DOM 轮询诊断。`npm start` 实测补渲 51 字符、无 setValue 报错、启动即恢复笔记正文。详见 `doc/历史Bug记录.md` Bug-026。

- **2026-09-09（修复·Bug-027）**：解决「设置调整主题后切回编辑器留白」——`loadView` 重建 DOM 时未销毁 vditor 实例，模块级 `vdInst` 残留已失效引用，切回时 `ensureVd` 不重建。改为离开编辑器视图前于替换 DOM 处显式 `vdDestroy()` 释放引用，返回时在新 DOM 上重建。CDP（9223）实测切设置再切回编辑区正常渲染。详见 `doc/历史Bug记录.md` Bug-027。

- **2026-09-09（修复·Bug-028）**：解决「设置-外观选『跟随系统』后切回设置视图主题回退为深色」——`window.__savedTheme` 等启动快照只在启动时读取一次，`setTheme/setAccent/字体` 持久化时从不更新快照，视图重建恢复路径用旧值回退。改为持久化时同步 `window.__saved*` 快照（方案 A）。jsdom 8 项断言通过，回归断言入 `regression.test.js`。详见 `doc/历史Bug记录.md` Bug-028。

- **2026-09-09（新增·IR 表格右键菜单）**：vditor 原生「表格浮层工具栏」只在所见即所得(wysiwyg)模式出现（`wd.wysiwyg.popover`）。为即时渲染(IR，默认编辑节点)补一个等价入口——在 IR 编辑区表格单元格内**右键**弹出菜单：「在上方/下方插入行、在左/右侧插入列、删除该行、删除该列」。同步关键：IR 下 vditor `getValue` 恒按 `ir.element.innerHTML` 实时推导 markdown，故直接在 `vdInst.vditor.ir.element` 的真实 `<table>` DOM 增删行/列后调 `getValue()` 并 `sync2Host` 保存即可，不触发内部重渲染、光标不跳转。纯 DOM 助手导出到 `window.__vdTable`，回归断言 `testIrTableBarHelpers` 入 `regression.test.js`，`npm test` 56 通过 0 失败。**边界收敛**：表头行(th)「下方插入行」强制落到 `|---|` 分隔线之下（tbody 首行，不串进 thead，新行一律为数据格 td）；表头行不可在上方插入行、不可删除该行（右键菜单对其隐藏这两项），与 vditor 原生 `insertRow/deleteRow` 语义对齐，`npm test` 59 通过 0 失败。

- **2026-09-09（修复·Bug-033）**：解决「软件第一次启动要十几秒」——未配置单实例锁，托盘常驻/残留进程后再双击启动会与旧实例并发，渲染进程争用磁盘/CPU，第二个实例 `did-finish-load` 被拖慢到 12+ 秒。改为启动前 `app.requestSingleInstanceLock()`：未获锁实例直接 `app.quit()`，获锁实例监听 `second-instance` 恢复既有窗口，`whenReady` 加 `if (!gotTheLock) return;` 守卫。实测单实例冷启动渲染 1.1s；双实例并发仅 1 条 `whenReady_begin`、唯一实例渲染 1.1s 无卡顿。保留精简 `[startup]` 阶段打点日志便于后续排查。`npm test` 回归 59 通过 0 失败。详见 `doc/历史Bug记录.md` Bug-033。
