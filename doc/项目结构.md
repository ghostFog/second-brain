# 项目结构（第二脑 / second-brain）

> **本文档为项目目录结构的唯一权威来源。** 结构变更时同步更新本文档，并遵循 `AGENTS.md`「文档同步规则」。
> 原文曾内嵌于 `.hermes/project.md`，现独立成文并迁至 `doc/`（2026-09-04）。

## 项目概览

- **项目名称**：第二脑（工程目录 `second-brain`）—— Obsidian 风格的笔记应用

- **形态**：桌面程序（Electron 主）+ 网页版（调试辅助）

- **技术栈**：Electron + 原生 HTML / CSS / Tailwind（本地化）/ Lucide 图标 / hash 路由 SPA

- **本地 AI**：`@xenova/transformers`（分词/嵌入）+ `onnxruntime-node`（重排序），本地向量索引与语义检索

- **设计基调**：单品牌色 Violet `#7C3AED`，深/浅双主题，Design Token 驱动

## 目录/文件职责与注意事项

| 路径                           | 职责                 | 注意                                                  |
| ---------------------------- | ------------------ | --------------------------------------------------- |
| `doc/`                       | 设计、需求、进度、结构唯一权威    | 变更界面前必查设计/需求文档；结构变更同步更新本文件                          |
| `.hermes/`                   | 规则导览 + 编码规范        | 仅 `project.md`/`coding-style.md` 承载正文，其余重定向到 `doc/` |
| `second-brain/AGENTS.md`   | 工程级就近规则（模块速览/常用命令/规范引用） | 智能体在 `second-brain/` 内就近读取；权威正文仍懒加载自 `doc/` |
| `second-brain/views/`      | 各 hash 视图页面        | 新增视图须同步 Ribbon 导航与 `js/app-*.js` 路由                 |
| `second-brain/js/vendor/`    | 本地化第三方库            | 禁止从 CDN 加载，须在离线可用                                   |
| `second-brain/js/app-*.js`   | 全部视图交互 + 路由（按模块拆分） | 新增功能点先查需求/设计文档；修改视图逻辑按模块定位对应文件                      |
| `second-brain/js/editor/`    | 编辑器宿主模块（core/host/tabs/filetree/sidepanel/md/ctx/vditor 等） | 编辑器能力由后缀对应插件接管（Provider 契约，见 需求-插件.md）          |
| `second-brain/js/settings/`  | 设置视图模块（core/ai/appearance/shortcuts/plugins/panels/main） | 多文件共享全局词法作用域；main 须最后引入                          |
| `second-brain/main.js`       | Electron 主进程       | 窗口、note:// 协议、窗口控制 IPC                              |
| `second-brain/ai-engine.js`  | AI 引擎（主进程共用）       | 本地 ONNX + 远程/本地大模型，被 IPC 调用                         |
| `second-brain/dist/`         | 打包产物               | 勿手动编辑；`npm run dist` 生成                             |
| `second-brain/node_modules/` | 依赖                 | 勿手动编辑；内含第三方自带测试文件，勿清理                               |

## 关键要点

- 应用为 **hash 路由 SPA**：`index.html` 依次引入 `js/app-*.js` 及模块目录 `js/editor/`、`js/settings/`，其中 `app-layout.js` 的 `loadView()` 按 hash 动态加载 `views/*.html`。

- **桌面版**：`electron .`（`npm start`）启动，`main.js` 加载 `index.html` 并启用 `note://` 协议。

- **网页版调试**：`start-server.bat` 起本地 http 服务器，访问 `http://127.0.0.1:8000/index.html`。

- **打包**：`npm run dist`，产物在 `second-brain/dist/`。

- `NoteApp` 已于 2026-09-02 更名为 `second-brain`，命令/路径一律用新目录名。
