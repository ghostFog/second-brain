# Bug-050 · 打开软件编辑器内容「闪烁→空白」，切换 Ribbon 再切回才恢复——多次构建的实例异步 after 乱序抢占暂存内容。

> [返回 Bug 索引](../历史Bug记录.md) ｜ 状态：已修复（测试完成）

- **ID**: Bug-050
- **日期**: 2026-09-12
- **现象**: 打开软件（或刷新页面）、且上次记忆的编辑模式为「所见即所得（WYSIWYG）」时，编辑器先闪烁一下笔记内容，随即变成空白（编辑区 DOM 正常、WYSIWYG 节点 `display:block` 但内容为空）；点击 Ribbon 导航切换到其它视图再切回编辑器（触发视图重建）才恢复显示。即时渲染（IR）模式下偶发。
- **复现地点**: `js/editor/editor-vditor.js`（`buildVditor` 的 `options.after` 回调，与模块级 `vdPending` / `vdReady` / 松散 `vdInst` 引用）
- **原因**: 启动路径 `initEditor` 会连续构建多个 vditor 实例：①`vdInit()` 先以默认 `vdMode='ir'` 构建实例 A；②恢复上次记忆模式（如 `wysiwyg`）时 `vdSetEditorNode` 重建实例 B。两次构建各自触发一个**异步** `options.after` 回调，但该回调读写的 `vdPending`/`vdReady` 是**实例无关的模块级共享状态**。若实例 A 的 after 恰好在实例 B 的 after 之前完成（异步乱序），A 的 after 会：
  - 把 `vdPending`（`renderArticle → vdSyncValue` 暂存的待补渲内容）消费并 `setValue` 到已销毁/不再显示的实例 A 上；
  - 将 `vdPending` 置空、`vdReady` 置 true。
  随后实例 B（真正显示的那个）的 after 触发时，`vdPending` 已为 `null`，走 `pending===''` 分支不补渲 → 当前 WYSIWYG 实例内容为空，即「闪烁后空白」。切 Ribbon 再切回会重建视图并重新渲染内容，故恢复。
- **状态**: 已修复（测试完成）
- **处理方法**: 给每次 `buildVditor` 加一个自增构建序号 `vdBuildSeq`，`options.after` 在消费暂存内容 / 接管显隐**之前**校验自己是「最新一次构建」：`if (seq !== vdBuildSeq) return;`。旧实例的乱序 after 直接放行，不抢 `vdPending`、不置 `vdReady`，待真正当前实例的 after 消费补渲。改动集中在 `editor-vditor.js`：
  ```js
  let vdBuildSeq = 0;                                     // 追加模块级构建序号
  // buildVditor 内
  const seq = ++vdBuildSeq;                               // 本次构建序号
  // options.after 回调开头
  if (seq !== vdBuildSeq) return;                         // 非最新实例：乱序 after 放行，不消费暂存内容
  ```
- **验证结果**:
  - CDP 实机（web 版）用 `debug-startup-blank.mjs` 在 `localStorage` 预置 `note-app:settings={sbEditorMode:'wysiwyg'}` 后刷新模拟启动，连续 3 次：WYSIWYG 编辑区均渲染出真实笔记内容（如 `9月目标完成 [[深度工作]]、[[Re…`），不再空白；IR 模式同样正常。
  - `regression.test.js` 新增 3 条断言（`testVditorBridge` 末尾）：旧实例 `after` 乱序先触发不抢占 `vdPending`；最新实例 `after` 消费补渲内容；补渲后 `getValue` 返回最新内容。`npm test` 144 通过、0 失败。
- **防再犯要点**: 多次构建第三方编辑器（vditor 等）实例、且其后渲染回调**异步乱序触发**时，凡回调要消费「模块级共享暂存状态」（如 `vdPending`/`vdReady`）来控制首个/当前实例的内容补渲，必须用「本轮构建序号」锁定回调只对**最新一次构建**生效；否则旧实例的回调会抢先消费共享状态，把内容塞到已销毁实例上，当前实际显示的实例补渲落空→空白（CD-37 新增）。
