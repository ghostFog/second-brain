# Bug-054 · 多窗口时点击关闭按钮，所有窗口都关闭了

> [返回 Bug 索引](../历史Bug记录.md) ｜ 状态：已修复（测试完成）

- **ID**: Bug-054
- **日期**: 2026-09-14
- **现象**: 多窗口场景（打开两个及以上知识库窗口）下，点击任一窗口的关闭按钮(×)，**所有窗口全部关闭**（应用退出）；预期应只关闭当前窗口，最后一个窗口关闭才退出程序（G-13 窗口级生命周期）。
- **复现地点**: `main.js` `ipcMain.on('win:close')` 多窗口分支
- **原因**: 关闭按钮分派逻辑中，多窗口分支仍尊重全局 `closeAction` 设置——当设置（或首次询问所选）为 `closeAction='quit'` 时，点击关闭按钮直接执行 `app.quit()` 退出整个应用，关闭所有窗口；`closeAction='tray'` 时也会把当前窗口藏到托盘（skipTaskbar 移出任务栏），行为与「关闭按钮只关当前窗口」的窗口级语义冲突。
- **状态**: 已修复（测试完成）
- **处理方法**: `win:close` 多窗口分支（存活窗口数 > 1）统一执行 `win.close()` 只销毁当前窗口，**不再受 `closeAction` 影响**（移除 quit/tray 特判）；最后一个窗口关闭后由既有 `window-all-closed → app.quit()` 退出程序。单窗口行为保持不变（首次询问 + closeAction 分派）。
- **验证结果**:
  - 语法检查 `node -c main.js` 通过；`npm test` 163 通过、0 失败。
  - 手动冒烟：启动应用（单窗口）→ 关闭窗口 → 正常退出（exit 0）、日志无 `uncaughtException`。
  - 多窗口「关闭当前窗口、其余窗口保留」由用户手动交互验证。
- **防再犯要点**: 多窗口（窗口级生命周期）语义下，关闭按钮必须**只作用于当前窗口**，不得被全局「退出应用/缩小托盘」设置劫持——全局 closeAction 只在**单窗口**场景生效；判断分支要按「存活窗口数」而非 closeAction 决定退出行为（CD-41 新增）。
