# Bug-064 · 编辑工具栏「宽屏/表格列宽」按钮点击无效 + 预览代码块不显示行号

> [返回 Bug 索引](../历史Bug记录.md) ｜ 状态：已修复（测试完成）

- **ID**: Bug-064
- **日期**: 2026-09-22
- **现象**: ① ED-54 把「宽屏」「表格列宽」迁入 vditor 编辑工具栏后，点击两个按钮没有任何效果（不铺满宽度/列宽不变）；② 编辑器的代码块（预览/阅读面）不显示行号。
- **复现地点**: `editor-vditor.js`（VDTOOLBAR 的 `sb-wide`/`sb-table-layout` 点击回调）；`plugins/markdown-editor/main.js`（`mdeToggleWide`/`mdeToggleTableAuto`）；`buildVditor` 的 `preview` 配置
- **原因**: ① markdown-editor 插件经宿主 `new Function('PluginAPI','pluginId', joined)(PluginAPI,id)`（app-plugins.js 沙箱）执行，其**顶层 function 声明只在 `new Function` 造成的局部作用域内生效，不会挂到 `window`**；而迁入 vditor 工具栏的按钮点击回调写的是 `window.mdeToggleWide`/`window.mdeToggleTableAuto`，二者恒为 `undefined`，`typeof` 守卫直接短路，函数从不被调用。② vditor 预览/阅读代码块的行号属官方能力，需在 `preview.hljs.lineNumber: true` 中开启，当前 preview 配置未设 `hljs`；且 vditor 打包的 `dist/index.css` **不含 `.hljs-ln` 行号样式**，即便开启也会因缺样式不显示行号数字。
- **状态**: 已修复（测试完成）
- **处理方法**: ① 插件 `main.js` 末尾显式把能力导出到全局：`window.mdeToggleWide = mdeToggleWide; window.mdeToggleTableAuto = mdeToggleTableAuto;`，使 vditor 工具栏按钮经 window 桥接可用（未启用插件仍由 `typeof` 守卫安全降级）。② `editor-vditor.js` 的 `buildVditor` preview 配置追加 `hljs: { lineNumber: true }` 开启代码块行号；并在 `css/app.css` 追加 `.vditor-reset ... .hljs-ln` 行号列样式（行号以 `.hljs-ln-numbers::before` 取 `data-line-number` 显示），覆盖 vditor 对代码块表格的默认样式。
- **验证结果**: `node --check` 语法通过；npm test 247 通过、0 失败。真机待验证：① 点击工具栏「宽屏/表格列宽」按钮，编辑区内容分别铺满 100% / 表格列宽随内容变化（`html.ed-wide`/`html.fe-table-auto` 类生效）；② 预览/分屏右预览/阅读模式代码块左侧出现 1..n 行号。
- **防再犯要点**: ① 插件经 `new Function` 沙箱执行时顶层 function 声明**不成为 window 全局**：跨上下文的宿主↔插件能力调用，必须由插件**显式 `window.xxx = f` 导出**后再经 `window.xxx` 引用，禁止直接假定顶层函数全局可见。② vditor 预览代码块行号能力 = **`preview.hljs.lineNumber:true`（配置开启）+ 自定义 `.hljs-ln*` CSS（vditor 自带 CSS 不含行号样式）**，二者缺一即不显示。
