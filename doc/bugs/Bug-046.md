# Bug-046 · 编辑器须做「主题配色数值映射」：编辑区跟随主题颜色，并兜底深色下文字可读

> [返回 Bug 索引](../历史Bug记录.md) ｜ 状态：已修复（测试完成）

- **ID**: Bug-046
- **日期**: 2026-09-10
- **现象**: ① 上一版把编辑主题退化为「只跟随宿主明暗、不做配色映射」后，vditor 的 `.vditor-reset` 硬编码 `color:#24292e`（浅色文字）在**深色主题**下与深色背景同色，正文/标题灰暗不可读（见截图：DevTools 显示 `index.css:831 .vditor-reset{color:#24292e}`）。② 需求明确「深色/浅色/跟随系统」只记录宿主明暗作为编辑器深浅打底，同时编辑器要做**主题配色数值映射**——把当前生效的配色值映射进编辑区，使编辑器颜色随主题色的调整保持一致。
- **复现地点**: `plugins/minimal-theme/main.js`（`buildEditorCss` / `editorThemeResolver` / `injectCss`）+ `css/app.css`（`#ed-vditor .vditor` 的 `--vditor-*` 变量映射、`.vditor--dark .vditor-reset` 兜底）
- **原因**: 移除配色→编辑器映射且不补 `.vditor-reset` 文字兜底，导致 vditor 自带浅色默认文字 `#24292e` 在深色外壳上不可读；且未满足「配色数值映射进编辑器」的产品诉求。
- **状态**: 已修复（测试完成）
- **处理方法**: 恢复「主题配色数值映射进编辑器」：
  ① `plugins/minimal-theme/main.js`：恢复 `buildEditorCss()` —— 把当前生效的 `--note-background/--note-surface/--note-card/--note-border/--note-line/--note-ink/--note-ink-2/--note-ink-3/--note-brand/--note-brand-ink` 数值映射进 vditor 壳与内容层（编辑区背景/工具栏/表格/表头/引用/代码/链接/分隔线/callout/选中态），**只用主题变量、不回落固定色值**；`.vditor-reset` 文字取 `var(--note-ink)` 兜底浅色默认字。`editorThemeResolver` 按 `hint.dark` 套 vditor 深浅主题打底，开关注入映射（`injectCss`，默认开）并叠加用户「自定义编辑器CSS」；settings 监听恢复 `injectCss` 分支。
  ② `plugins/minimal-theme/manifest.json`：恢复 `injectCss`（「同步宿主配色到编辑器」，默认 true）设置项。
  ③ `css/app.css`：恢复 `#ed-vditor .vditor`/`.vditor--dark` 的 `--vditor-background/--vditor-text-color/--vditor-border-color/--vditor-toolbar-background/--vditor-toolbar-color` 映射，并恢复 `.vditor--dark .vditor-reset{color:var(--note-ink)}`（与插件 `.html body .vditor-reset` 覆盖互为双保险）。
  ④ `js/editor/editor-vditor.js`：无插件解析器时 fallback 按宿主明暗返回 `{ theme: hint.dark ? 'dark' : 'light', extraCss: '' }`（保留）。
- **验证结果**: 更新回归 Bug-046（存在 `buildEditorCss` 且 `.vditor-reset` 字母映射 `var(--note-ink)`、表格/表头映射主题色、buildEditorCss 段不回退固定色值、按 `injectCss` 开关注入、manifest 含 `injectCss` 且无 `edTheme`）；同步更新 `smoke-plugin.test.js`（深/浅宿主返回 theme + 配色数值映射、映射含 `.vditor-reset` 兜底、无固定值回落、`injectCss=false` 关闭后无注入、can叠加自定义CSS）；`npm test` 93 通过、0 失败；`smoke-plugin.test.js` 109 通过、0 失败。
- **防再犯要点**: 「深色/浅色/跟随系统」仅作为编辑器深浅打底（套 vditor 原生深/浅主题），**编辑器的具体颜色必须做主题配色数值映射**（`.vditor-reset` 文字色、表格、内容层一律取 `--note-*` 变量，不得依赖 vditor 自带的浅色默认文字），否则深色下 `.vditor-reset{color:#24292e}` 会导致正文不可读（CD-33 更新：从「禁止映射」改为「必须映射 + 兜底深色文字」）。
