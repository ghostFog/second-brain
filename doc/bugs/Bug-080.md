# Bug-080 · 表格单元格中 Ctrl+V 粘贴多行多列内容（如 Excel 复制）全部堆进一行/单元格

| 字段   | 说明                                                                                  |
| ---- | ----------------------------------------------------------------------------------- |
| ID   | Bug-080                                                                             |
| 日期   | 2026-10-26                                                                          |
| 现象   | 在 vditor 表格单元格中按 Ctrl+V，若剪贴板是从 Excel/其他表格复制的 **tab 分隔多行多列内容**（如 `1\t2\t3`），vditor 会整段塞到当前单元格变成一行。 |
| 根因 v1 | **第一版**用 `paste` 事件拦截。**太晚了**——paste 事件在浏览器/VDitor 已经把内容塞进 contenteditable DOM **之后**才触发，`preventDefault()` 对已发生的 DOM 变更无能为力。 |
| 根因 v2 | vditor **不处理 paste 事件**的表格语义——它依赖浏览器原生 paste，后者只是把剪贴板纯文本塞进 contenteditable 元素。没有任何代码解析 tab 分隔、\n 行分隔并分发到对应单元格。 |
| 修复 v3 | **最终方案**：两个拦截器配合——<br>1. `beforeinput`（capture 阶段）**主入口**：检查 `inputType === 'insertFromPaste'` + 光标在 TD/TH 内 → `preventDefault()` **阻止浏览器修改 DOM** → 解析 `e.data`（insertFromPaste 时 Chrome 会填这个）并分发<br>2. `paste`（capture 阶段）**兜底**：某些 Electron 版本 beforeinput `e.data` 可能为空，从 `e.clipboardData.getData('text/plain')` 取<br>分发函数复用：`vdPasteTableGrid(cellEl, text)` 按 `\r?\n` 分行、`\t` 分列，从活动 cell 逐格填充，超出边界自动扩展行列。 |
| 状态   | 已修复（测试完成）                                                                   |
| 防再犯要点 | **CD-60**：contenteditable 富文本编辑器的表格单元格粘贴，**必须在 `beforeinput` 阶段拦截**（`inputType === 'insertFromPaste'`）并 `preventDefault()` 阻止默认 DOM 变更——**`paste` 事件拦截太晚**（DOM 已改，preventDefault 无效）。capture 阶段 + `e.stopImmediatePropagation()` 屏蔽 vditor 原生处理。解析剪贴板按 `\r?\n` 分行、`\t` 分列，从活动 TD/TH 坐标逐格填充，超出边界自动 insertRow/insertColumn 扩展。Electron 环境下 beforeinput 的 `e.data` 可能为空，需保留 `paste` 事件从 `clipboardData` 取内容作为兜底。 |

---

## 最终方案

### 架构

```
Ctrl+V 触发
  → beforeinput (capture, inputType='insertFromPaste')
    → 光标在 TD/TH 内？
      → YES + e.data 有值: preventDefault → vdPasteTableGrid(cellEl, e.data)
      → YES + e.data 为空: 放行（让 paste 兜底）
      → NO: 放行

  → paste (capture, 兜底)
    → 光标在 TD/TH 内？
      → YES + clipboardData 有值: preventDefault → vdPasteTableGrid(cellEl, text/plain)
      → NO: 放行
```

### 核心分发函数 vdPasteTableGrid

- 解析 `\r\n / \r / \n` 分行、`\t` 分列 → 得到 `grid[row][col]`
- 定位 `cellEl` 在 `tableEl.rows` 中的坐标（遍历 thead + tbody 所有行）
- 逐格 `cell.textContent = val`，空值写 `<br>` 保证 contenteditable 可 focus
- 超出行数 → 克隆最后一行结构 append
- 超出列数 → 克隆最后一个单元格 tag append
