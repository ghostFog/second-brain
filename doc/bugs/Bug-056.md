# Bug-056 · Minimal Theme 插件顶栏图标缺失 + 切换主题快捷键 Ctrl+Q 未生效

> [返回 Bug 索引](../历史Bug记录.md) ｜ 状态：已修复（回归通过）

- **ID**: Bug-056
- **日期**: 2026-09-14
- **现象**:
  1. Minimal Theme 插件标题栏顶栏图标丢失（本应出现在顶栏工具栏）。
  2. 切换主题的默认快捷键 Ctrl+Q 未生效（cycle-theme 命令无法用 Ctrl+Q 触发）。
- **复现地点**: `js/app-plugins.js`（`initPluginSystem` 安装内置 mock + `loadDirPlugins` 异步加载目录插件）+ `plugins/minimal-theme/manifest.json`（`commands` 声明）
- **原因**: `initPluginSystem` 先安装内置 mock `minimal-theme`（声明 ribbon），`loadDirPlugins` 异步加载目录插件（声明 toolbar + `cycle-theme` 命令）时，`pluginManager.install` 内 `installedPlugins.find(p => p.id === plugin.id)` 按 **id 去重直接 return 跳过**，导致目录插件声明的顶栏按钮 / 命令与默认快捷键从未注册；同时 manifest 中 `cycle-theme` 命令未声明 `shortcut: Ctrl+Q`。
- **状态**: 已修复（回归通过）
- **处理方法**:
  1. `js/app-plugins.js` `loadDirPlugins` 中，install 前先对**同 id 旧条目 `uninstall`**，让目录插件的扩展点（顶栏图标、`cycle-theme` + Ctrl+Q）真正生效。
  2. `plugins/minimal-theme/manifest.json` 的 `cycle-theme` 命令补充 `"shortcut": "Ctrl+Q"` 默认快捷键声明。
  3. 在 `regression.test.js` 新增 `testDirPluginToolbarOverride`，5 条断言覆盖：①install 前同 id 先 uninstall；②manifest 声明 Ctrl+Q；③顶栏按钮渲染到 `#plugin-toolbar`；④快捷键注册表 `cycle-theme` 组合为 Ctrl+Q；⑤Ctrl+Q 全局键命中 `minimal-theme:cycle-theme`。
- **验证结果**: 语法检查通过；`npm test` 163 通过、0 失败（含 Bug-056 新增断言）。
- **防再犯要点**: 内置 mock 与目录插件同 id 时，目录插件必须覆盖内置（扩展点与默认快捷键以目录插件为准）；目录插件的命令默认快捷键须在 manifest `commands` 中显式声明 `shortcut`，否则快捷键不入注册表（CD-43 新增）。
