# Bug-048 · 编辑器区右键菜单永不弹出——命中判定用了不存在的 `vdInst.element`。

> [返回 Bug 索引](../历史Bug记录.md) ｜ 状态：已修复（测试完成）

- **ID**: Bug-048
- **日期**: 2026-09-12
- **现象**: 在编辑区（vditor IR/所见即所得）右键，本应弹出的「插入图片 / 上传附件」自定义菜单（`.sb-ctx`）始终不出现。「醒目指示块」（`> [!attach]` 附件引言）在编辑区确能正常渲染，但右键无任何反应。
- **复现地点**: `js/editor/editor-vditor.js`（`onEditorContextMenu`，`document.addEventListener('contextmenu', onEditorContextMenu)`）
- **原因**: `onEditorContextMenu` 用 `vdInst.element && vdInst.element.contains(e.target)` 判断右键是否落在编辑区内，但 Vditor 实例**从不挂 `element` 字段**——真实内容容器是 `vdInst.vditor.element`。`vdInst.element` 恒为 `undefined`，`vdInst.element && …` 短路为假，命中判定永远失败，菜单分支永不进入。即使右键菜单定义、上传助手、attach 指示块等其它逻辑都正确，这一处错误容器断言让整条入口静默失效。
- **状态**: 已修复（测试完成）
- **处理方法**: 命中判定改用 vditor 真实暴露的内容容器 `vdInst.vditor.element`，缺省回退视图锚点 `vdEl()`（`#ed-vditor`）：
  ```js
  const vdRoot = (vdInst && vdInst.vditor) ? vdInst.vditor.element : (vdEl() || null);
  if (vdInst && e.target && vdRoot && vdRoot.contains(e.target)) { … }
  ```
  `vdInst.vditor.element` 为 `.vditor-content` 内容区（含 ir/wysiwyg/sv/preview），工具栏在其外层；右键内容区弹编辑菜单、右键卡片走卡片菜单、右键工具栏不劫持，语义正确。
- **验证结果**: 用 lute 离线实测两种 attach 形式均正常渲染指示块与预览卡片（clean 与往返链化 `[url](url)` 经 `textContent` 剥离后均能提取 url）；新增回归断言（`testEditorRightClickUpload` 增补 2 条）：命中判定不得再用 `vdInst.element`、必须引用 `vdInst.vditor.element` 或 `vdEl()`。`npm test` 137 通过、0 失败。
- **防再犯要点**: 判断右键/事件是否落在第三方编辑器（vditor 等）内容区内时，容器元素必须取自实例真实暴露的引用（`vdInst.vditor.element`）或视图锚点元素，绝不能臆想一个不存在的属性（如 `vdInst.element`）做 `contains` 判定——不存在的引用恒为 `undefined`，`contains` 判定恒假，事件入口静默失效（CD-35 修正）。
