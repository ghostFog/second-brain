# Bug-058 · 点击编辑器工具栏链接按钮报错 className.slice is not a function

> [返回 Bug 索引](../历史Bug记录.md) ｜ 状态：已修复（测试完成）

- **ID**: Bug-058
- **日期**: 2026-09-15
- **现象**: 点击编辑器工具栏的链接按钮时控制台报未捕获错误：`Uncaught TypeError: (e.target.className || "").slice is not a function @ note://local/index.html:1881`。
- **复现地点**: `second-brain/plugins/markdown-editor/md-linknav.js`（`#ed-vditor` 文档级 click 监听，调试日志行）
- **原因**: 该监听用 `e.target.closest('#ed-vditor')` 把 vditor 容器整体（含工具栏）纳入检测。点击工具栏链接按钮时，`e.target` 命中按钮内的 **SVG 图标元素**，其 `className` 是 `SVGAnimatedString` 对象（非字符串，无 `.slice` 方法），直取 `(e.target.className || '').slice(...)` 便抛 `is not a function`，导致整个 click 处理器崩溃。
- **状态**: 已修复（测试完成）
- **处理方法**: 取 className 时对元素类型做守卫——`className` 是字符串才能 `.slice`；SVG 元素改用 `getAttribute('class')` 取字符串。
- **验证结果**: `node --check` 语法通过；`npm test` 163 通过、0 失败。
- **防再犯要点**: 对任意 `e.xxx.className` 的读取，若目标可能是 SVG 元素（`className` 为 `SVGAnimatedString`），必须先判断 `typeof className === 'string'` 或改用 `getAttribute('class')`，禁止对可能含对象/数组的 `className` 直接调字符串方法（`slice`/`split`/`match` 等）。（CD-45 新增）
