# 文档读取路由（最小路径）

> **本文档是 AGENTS 启动后决定「该读哪些文件」的唯一权威路由。**
> 目的：节省 token——每次任务只读**最小必要集**，不再强制通读所有文档。
> 用法：按下方「任务类型」或「模块」定位，命中即只读对应文件；未命中时回到 `doc/功能需求文档.md` 模块导航枚举。

## 一、通用必读（所有任务）

只读本路由文件即可，其余一律按需。

- `AGENTS.md` —— 行为规则与（可选）详细规范入口，本路由已覆盖其「每次任务必须读取」的定位职责。

## 二、任务类型 → 最小必读

| 任务类型 | 最小必读（必须查） | 按需可选 |
| --- | --- | --- |
| **新增/修改功能（编码）** | `doc/需求/需求-<模块>.md`（做什么）+ `doc/设计/设计-<模块>.md`（长什么样/交互） | `doc/开发进度.md`（未完结看板，去重/推进）；登记新需求再查 `doc/功能需求文档.md` 编号表 |
| **Bug 定位/修复** | `.hermes/bug-tracking.md`（规则）+ `doc/历史Bug记录.md`（去重） | `second-brain/regression.test.js`（补回归断言） |
| **打包发布/新版本** | `second-brain/package.json` + `second-brain/js/changelog.js` | `doc/开发进度.md`、`doc/功能需求文档.md`（登记条目） |
| **插件开发** | `doc/plugins/index.md` + 对应插件规划 `.md` + `doc/插件开发规范.md` | `doc/设计/设计-插件.md`、`doc/设计/设计-编辑器.md`（editor 类插件） |

## 四、原则

- **最简优先**：能用模块文件解决就不读全局导航；能用一份就不读三份。
- **按需追加**：先读最小集，不够再向上扩容（模块→导航→权威正文），不反向全量读。
- **设计稿**：仅「改界面/视觉」才读 `design/pages/*.html`，纯逻辑/数据任务不必读。
- **登记类操作**（新增需求、推进进度、记录 Bug）：只读对应模块文件做登记，不读设计正文。
