# 第二脑 · 设计文档：设置

> 对应需求模块 `需求-设置.md`（ST-xx），含「设置 - AI 问答分类」。

## 6.1 分类侧边栏（宽 220px）

分类导航：外观 / 编辑器 / 快捷键 / 同步与备份 / 隐私与安全 / 插件管理 / 关于；点击切换，选中态高亮。

## 6.2 外观面板

- **主题模式**：深色 / 浅色 / 跟随系统（卡片选择，选中显示对勾）；

- **强调色**：6 色圆点（紫 / 蓝 / 绿 / 橙 / 红 / 粉）；

- **字体大小**：滑块 14–18px，默认 15px；

- **字体族**：Inter / Noto Sans SC / 系统默认（下拉选择）；

- **代码字体**：JetBrains Mono / Fira Code / Cascadia Code（下拉，切换生效并持久化）；

- **界面密度**：紧凑 / 标准 / 舒适（卡片选择，切换行高生效）；

- **显示行号**：toggle 开关（控制编辑区 / 代码块行号）；

- **自动换行**：toggle 开关（控制编辑区长文本折行）；

- **减少动画**：toggle 开关（全局禁用过渡与动画，根元素标记 `data-reduce-motion`）。

> 其余分类（编辑器、快捷键、同步与备份、隐私与安全、插件管理、关于、AI 问答）：当前为导航入口，详细设置项随需求补充；每分类以**占位说明卡**呈现，避免空屏。

> 设置中「代码字体」「自动换行」「减少动画」「显示行号」「界面密度」等项均**真实生效并持久化**（写入 CSS 变量 / `<html>` 标记 / `localStorage`）。

## 6.3 设置 - AI 问答分类

- **本地模型**：嵌入模型路径 + 重排序模型路径（默认指向 `models/` 目录下两个本地模型）；

- **生成模型列表**：列表展示多个生成模型（供应商 + 模型名称 + 当前标记），支持添加/编辑/删除；

- **添加/编辑弹层**：提供方（本地 Ollama / 远程大模型 OpenAI 兼容）+ 接口地址 + API Key + 模型名称；

- **状态与索引**：嵌入模型加载状态、索引状态与「重建索引」按钮。
