# 第二脑 · 设计文档：图谱视图

> 对应需求模块 `需求-图谱视图.md`（GR-xx）。

## 4.1 左侧过滤面板（宽 220px，可滚动）

- **标签过滤**：勾选列表，圆点 + 名称 + 计数，头显"已选 / 总数"。

- **连接深度**：1层 / 2层 / 3层 + 滑块视觉 + `2层` 徽标。

- **节点类型过滤**：笔记 / 文件夹 / 标签，带图标 + 计数。

- **重置**：`rotate-ccw` 按钮一键还原所有过滤条件。

## 4.2 顶部工具栏（高 40px）

- **布局切换**：力导向 / 层级（选中态品牌色）+ 分隔线。

- **节点统计**：节点 10 · 连接 14。

- **缩放控制**：`-` 缩小 / % / `+` 放大 / 重置视图。

## 4.3 中间画布（SVG）

- **节点**：渐变节点（中心 / 普通 / 高亮）+ 名称标签，节点带连接数徽标，对应笔记 / 文件夹 / 标签。

- **连线**：一级粗线、二级弱线。

- **脉冲动画**：中心及侧节点放射波纹（装饰）。

- **图例**：左下角展示当前节点 / 选中 / 普通节点颜色示例。

- **操作提示**：右下角「拖拽平移 · 滚轮缩放」。

- **真实数据**：节点 / 连线由笔记库 `.md` 解析 `[[内链]]` 生成（`noteStore.list()`），替代写死 SVG；网页版无桥用 seed 数据。

- **过滤联动与重置**：标签勾选 / 节点类型勾选 → 显隐对应节点与连线，`已选 / 总数` 计数联动；布局（力导向 / 层级）真实切换；节点详情随选中节点数据更新；「重置」还原全部勾选、深度、布局与缩放。

## 4.4 右侧节点详情面板（宽 260px）

- 面板标题「节点详情」+ `info` 图标；

- 节点名称卡片：图标块 + 名称 + 分类徽标 + 连接数；

- 基本信息：创建时间 / 修改时间 / 字数；

- 标签：节点标签 chips（带色圆点）；

- 连接列表：关联节点列表，各带图标 + 连接方向箭头（入 / 出）+ 计数徽标，可点击、hover 态；

- 底部主按钮「打开笔记」`external-link`，点击打开对应笔记。
