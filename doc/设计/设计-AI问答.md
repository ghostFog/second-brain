# 第二脑 · 设计文档：AI 问答

> 对应需求模块 `需求-AI问答.md`（AI-xx）。

> 整体「左会话侧栏 + 右主列」两栏布局（根容器 `view-row flex`），右主列为「上中下」纵向 flex-col：顶部工具栏 → 中间对话区（弹性）→ 底部输入区。

## 7.1 顶部工具栏（高 48px）

- **页标题**：「AI 问答」+ 副标题「基于本地知识库的语义问答」；

- **索引状态**：索引片段数 + 嵌入模型状态徽标；

- **操作**：「重建索引」`refresh-cw` 按钮 + 「新建会话」`plus` 按钮。

## 7.2 对话区（弹性）

- 用户气泡（右对齐，品牌色底白字）/ 助手气泡（左对齐，surface 底）；

- 助手回答流式逐字显示，生成中显示「停止」按钮；

- 回答底部「来源」折叠区：检索到的笔记片段（文件名 + 相似度 + 预览），点击打开对应笔记；

- 空态：居中提示「输入问题，从你的笔记库中寻找答案」。

## 7.3 输入区（底部）

- 同一行布局：左侧「生成模型」下拉选择器（由顶部工具栏移入底部输入区）+ 中间文本输入框 + 右侧「发送」按钮；

- Enter 发送、Shift+Enter 换行。

## 7.4 会话侧栏（左，宽 220px）

- 头部：「会话」标题 + 计数徽标 + 「收起」`panel-left-close` 按钮；
- 会话行：`message-circle` 图标 + 标题（以首条提问自动生成，超长截断）+ 活跃态强调色高亮 + 悬浮 `×` 删除按钮；
- 点击会话行切换当前会话，重新渲染该会话历史气泡；
- 收起后左缘浮现展开把手 `panel-left-open`，点击重新展开（仅 AI 视图有效）。
