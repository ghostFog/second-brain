# 第二脑 · 设计文档：全局框架

> 对应需求模块 `需求-全局框架.md`（G-xx）。含全局共享的「设计令牌与通用组件」。

## 0. 设计令牌与通用组件

### 0.1 品牌与色彩

- 主色（品牌色）：Violet `#7C3AED`，贯穿选中态、强调、链接、Chips、悬停指示、拖拽高亮等。

- 主题：深色（默认）/ 浅色两种，由 CSS 变量（Design Tokens）驱动，全局同步切换。

- 语义变量：`--note-background/foreground/card/popover/border/muted/primary/ink/ink-2/ink-3/surface/surface-2/brand-400` 等，界面统一引用，不硬编码色值。

### 0.2 圆角与字体

- 圆角：`--note-radius-sm/md/lg`，控件小圆角、卡片/浮层大圆角。

- 字体：正文 `--note-font-ui`（Inter / Noto Sans SC / 系统默认可切换），代码 `--note-font-mono`（JetBrains Mono / Fira Code / Cascadia Code 可切换）。

### 0.3 通用组件

- 按钮、开关（toggle）、下拉框、Chips、toast 轻提示、目录区拖拽条（`tree-resizer`）。

- 间距/尺寸以 4px 为基准步进。

## 1. 全局框架（共享壳）

所有页面共用同一「浏览壳」，由标题栏 + Ribbon + 状态点构成（G-01\~G-09）。

### 1.1 标题栏（高 36px）

- **左侧**：库选择器按钮（`book` 图标 + 库名 + 下拉箭头），点击展开库下拉框（见 1.1.1）；悬浮库名时 `title` 提示当前库绝对路径。

- **中间**：面包屑导航（如 日记 / 2024年 / 09月），末级高亮。

- **右侧**：命令面板触发按钮（`search` 图标 + "搜索" + 快捷键 `⌘P` 提示）；文档窗口控制（最小化 / 最大化 / 关闭，桌面版自绘、可拖拽，与 cmd 生命周期解耦）。

#### 1.1.1 库下拉框（桌面版，G-07 / G-09）

点击库名展开，浮层出现在库名正下方，底部空间不足时自动向上展开。三段结构，段间用分割线：

- **当前知识库**（顶部单独展示）：高亮显示当前库名，悬浮提示其绝对路径；下方分割线。

- **其他知识库**（分割线下列表）：默认知识库（显示「我的笔记库」）+ 最近打开的历史库合并为一个列表，剔除当前库、按路径（忽略大小写）去重、最近置顶、上限 12 条；点击库名即切换（`vault:switch`）；非默认库悬浮右侧出现较大的 `×`（更大点击区域），点击弹出二次确认，确定后仅从列表移除（`vault:remove`，不改当前库）；默认库不带 `×`；无其他知识库时占一行高度、灰色显示「无其他知识库」。

- **打开笔记库… / 迁移默认知识库… / 默认知识库**（下方分割线）：目录选择器（允许新建目录）选中即切换为当前库并记入历史（`vault:choose`）；迁移默认知识库（`vault:migrate`）弹目录选择器选目标（允许新建目录）→ 二次确认 → 以移动语义把默认知识库内容迁移到目标目录（复制成功后清空原默认库），迁移后该目录成为新的默认库并持久化到 `settings.json`（`defaultVaultPath`），原默认库路径从历史中移除；恢复默认笔记库回到当前默认库路径 `userData/vault`（或已迁移后的新默认库，`vault:reset`）。

- **持久化**：库历史写入 `userData/settings.json`；切换/恢复后整页刷新以重载当前笔记库。

### 1.2 Ribbon 导航（宽 48px，垂直）

顺序从顶到底：编辑器（`file-text`）/ 搜索（`search`）/ 图谱（`git-fork`）/ 插件（`puzzle`）/ 设置（`settings`）；下方弹性空隙，底部为**同步状态圆点**（绿色 = 已同步）。点击切换视图，选中项高亮。

### 1.3 笔记与目录右键（G-08 / ED-04）

- **笔记行右键**：文件树笔记行右键 → 弹出菜单「在资源管理器中显示」→ 桌面版调用 `shell.showItemInFolder`。

- **目录区空白右键**：空白处右键 → 新建笔记 / 新建目录 → 桌面版写入磁盘，空目录即时作为可展开文件夹出现在文件树。
