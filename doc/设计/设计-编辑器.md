# 第二脑 · 设计文档：主编辑器

> 对应需求模块 `需求-编辑器.md`（ED-xx）。

三栏布局：左侧文件树 + 中间编辑器 + 右侧面板。

## 2.1 左侧栏：文件树（初始宽 280px，可拖拽调宽）

- **栏头**：文件搜索输入框（占位"搜索文件…"）+ 新建笔记按钮（`plus`）。

- **文件树**：文件夹 / 子文件夹 / 文件的行结构；

  - 文件夹行：展开/折叠箭头 + `folder-open` / `folder` 图标 + 名称 + 计数徽标；空目录也可展开显示（计数 0）。

  - 文件行：`file-text` 图标 + 文件名 + 相对日期徽标（今天 / 昨天 / 2天前）；选中态品牌色底 + 白字。

- **栏脚**：统计（共 47 篇笔记）+ 存储（`hard-drive` 图标，2.4 MB）。

- **拖拽调宽**：目录区与编辑器之间 `tree-resizer` 拖拽条可调宽度（180–520px），宽度持久化到 `localStorage`（`settings.treeWidth`），重启恢复上次宽度。

- **右键**：见 `设计-全局框架.md` 1.3。

## 2.2 中间编辑器（弹性伸缩）

- **标签栏（高 36px）**：每文件一 Tab，可横向滚动；行尾 `pencil`（切换源码/所见即所得）`eye`（仅预览）/ `columns`（分屏，可再次点击关闭）切换视图；`more-horizontal` 更多菜单（占位）。

- **行号开关**：标签栏行尾新增 `list-ordered` 按钮，点击切换编辑区源码左侧行号显示，与设置「显示行号」开关联动并持久化（ED-32）。

- **查找 / 替换条**：`Ctrl+F` 打开查找条、`Ctrl+R` 打开替换条（编辑器顶部工具条）：查找输入即时计数（当前/总数）、上一下一按钮跳转并高亮选中匹配；替换输入支持「替换当前」「全部替换」；`Esc` 关闭（ED-33 / ED-34）。

- **正文区**：

  - Markdown 渲染：H1/H2、段落、列表、待办、行内代码 / 加粗 / 链接；

  - 待办勾选：方框 / 对勾 / 删除线；代码块：`terminal` + 语言标 + 复制按钮 + 语法染色；

  - 引用块：左侧品牌色竖线 + 斜体正文；文章标签区：正文底部标签 chips。

- **状态栏**：已自动保存 + Markdown + UTF-8 + 行 / 列 + 字数 + 中文，随编辑变化。

- **真实数据与保存**：文件树、正文、元信息由 `noteStore` 真实数据渲染（替代硬编码）；正文为可编辑（所见即所得），`input` 事件实时计字数/更新状态栏，并**防抖自动保存**（约 800ms）写入磁盘（`notes:save`）；新建 / 删除笔记真实写盘（`notes:create` / `notes:delete`）；网页版无桥时降级为内存 mock。

## 2.3 右侧面板（侧边面板 280px）

- **面板头部**：标题「侧边面板」+「展开全部」`chevrons-down-up` +「关闭面板」`panel-right-close`。

- **大纲**：笔记标题结构列表，H1 高亮、子标题缩进，点击跳转对应标题；可折叠 / 展开。

- **反向链接**：引用当前笔记的其它笔记卡片（文件名 + 相对日期 + 正文预览 + 内链 `[[xx]]` 高亮）+ 计数徽标，点击卡片打开对应笔记。

- **标签云**：全部标签 chips + 计数徽标，字号 / 深浅体现热度，点击筛选（占位）。

- **宽度拖拽 / 持久化**：面板左缘拖拽条（`side-resizer`，桌面端）调整宽度（220–440px），宽度持久化到 `localStorage`（`settings.sideWidth`）；与左侧目录区（`treeWidth`）一起在启动时恢复上次宽度。
