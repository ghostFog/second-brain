# 第二脑 · 设计文档：插件市场

> 对应需求模块 `需求-插件.md`（PL-xx）。

## 5.1 头部与筛选

- **页标题**：插件市场 + 副标题；

- **管理已安装插件**：`package-check` 按钮，点击弹出 / 跳转「已安装插件」列表（列出 `installed=true` 的插件）；

- **搜索插件**：占位"搜索插件..."，按名称 / 描述过滤卡片；

- **排序**：最热门 / 最新 / 评分最高（下拉切换）；

- **分类过滤**：全部 / 编辑器增强 / 主题外观 / 数据同步 / 生产力工具 / 集成服务（Chip 切换，选中态高亮）。

## 5.2 插件卡片

- 卡片信息：图标块、名称、作者、两行描述；

- 量化指标：下载量 + 评分；

- 安装 / 卸载：安装 或 已安装（可卸载）；已安装态显示对勾。

## 5.3 详情抽屉

点击插件卡片右侧滑出详情面板（默认折叠），展示插件完整信息。
