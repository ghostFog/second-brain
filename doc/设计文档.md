## 0. 设计令牌与通用组件

### 0.1 品牌与色彩

- 主色（品牌色）：Violet `#7C3AED`，贯穿选中态、强调、链接、Chips、悬停指示、拖拽高亮等。

- 主题：深色（默认）/ 浅色两种，由 CSS 变量（Design Tokens）驱动，全局同步切换。

- 语义变量：`--note-background/foreground/card/popover/border/muted/primary/ink/ink-2/ink-3/surface/surface-2/brand-400` 等，界面统一引用，不硬编码色值。

### 0.2 圆角与字体

- 圆角：`--note-radius-sm/md/lg`，控件小圆角、卡片/浮层大圆角。

- 字体：正文 `--note-font-ui`（Inter / Noto Sans SC / 系统默认可切换），代码 `--note-font-mono`（JetBrains Mono / Fira Code / Cascadia Code 可切换）。

### 0.3 通用组件

- 按钮、开关（toggle）、下拉框、Chips、toast 轻提示、目录区拖拽条（`tree-resizer`）。

- 间距/尺寸以 4px 为基准步进。

## 1. 全局框架（共享壳）

所有页面共用同一「浏览壳」，由标题栏 + Ribbon + 状态点构成（G-01\~G-09）。

### 1.1 标题栏（高 36px）

- **左侧**：库选择器按钮（`book` 图标 + 库名 + 下拉箭头），点击展开库下拉框（见 1.1.1）；悬浮库名时 `title` 提示当前库绝对路径。

- **中间**：面包屑导航（如 日记 / 2024年 / 09月），末级高亮。

- **右侧**：命令面板触发按钮（`search` 图标 + “搜索” + 快捷键 `⌘P` 提示）；文档窗口控制（最小化 / 最大化 / 关闭，桌面版自绘、可拖拽，与 cmd 生命周期解耦）。

#### 1.1.1 库下拉框（桌面版，G-07 / G-09）

点击库名展开，浮层出现在库名正下方，底部空间不足时自动向上展开。三段结构，段间用分割线：

- **当前知识库**（顶部单独展示）：高亮显示当前库名，悬浮提示其绝对路径；下方分割线。

- **其他知识库**（分割线下列表）：默认知识库（显示「我的笔记库」）+ 最近打开的历史库合并为一个列表，剔除当前库、按路径（忽略大小写）去重、最近置顶、上限 12 条；点击库名即切换（`vault:switch`）；非默认库悬浮右侧出现较大的 `×`（更大点击区域），点击弹出二次确认，确定后仅从列表移除（`vault:remove`，不改当前库）；默认库不带 `×`；无其他知识库时占一行高度、灰色显示「无其他知识库」。

- **打开笔记库… / 迁移默认知识库… / 默认知识库**（下方分割线）：目录选择器（允许新建目录）选中即切换为当前库并记入历史（`vault:choose`）；迁移默认知识库（`vault:migrate`）弹目录选择器选目标（允许新建目录）→ 二次确认 → 以移动语义把默认知识库内容迁移到目标目录（复制成功后清空原默认库），迁移后该目录成为新的默认库并持久化到 `settings.json`（`defaultVaultPath`），原默认库路径从历史中移除；恢复默认笔记库回到当前默认库路径 `userData/vault`（或已迁移后的新默认库，`vault:reset`）。

- **持久化**：库历史写入 `userData/settings.json`；切换/恢复后整页刷新以重载当前笔记库。

### 1.2 Ribbon 导航（宽 48px，垂直）

顺序从顶到底：编辑器（`file-text`）/ 搜索（`search`）/ 图谱（`git-fork`）/ 插件（`puzzle`）/ 设置（`settings`）；下方弹性空隙，底部为**同步状态圆点**（绿色 = 已同步）。点击切换视图，选中项高亮。

### 1.3 笔记与目录右键（G-08 / ED-04）

- **笔记行右键**：文件树笔记行右键 → 弹出菜单「在资源管理器中显示」→ 桌面版调用 `shell.showItemInFolder`。

- **目录区空白右键**：空白处右键 → 新建笔记 / 新建目录 → 桌面版写入磁盘，空目录即时作为可展开文件夹出现在文件树。

## 2. 主编辑器（editor）

三栏布局：左侧文件树 + 中间编辑器 + 右侧面板。

### 2.1 左侧栏：文件树（初始宽 280px，可拖拽调宽）

- **栏头**：文件搜索输入框（占位“搜索文件…”）+ 新建笔记按钮（`plus`）。

- **文件树**：文件夹 / 子文件夹 / 文件的行结构；

  - 文件夹行：展开/折叠箭头 + `folder-open` / `folder` 图标 + 名称 + 计数徽标；空目录也可展开显示（计数 0）。

  - 文件行：`file-text` 图标 + 文件名 + 相对日期徽标（今天 / 昨天 / 2天前）；选中态品牌色底 + 白字。

- **栏脚**：统计（共 47 篇笔记）+ 存储（`hard-drive` 图标，2.4 MB）。

- **拖拽调宽**：目录区与编辑器之间 `tree-resizer` 拖拽条可调宽度（180–520px），宽度持久化到 `localStorage`（`settings.treeWidth`），重启恢复上次宽度。

- **右键**：见 1.3。

### 2.2 中间编辑器（弹性伸缩）

- **标签栏（高 36px）**：每文件一 Tab，可横向滚动；行尾 `pencil`（切换源码/所见即所得）`eye`（仅预览）/ `columns`（分屏，可再次点击关闭）切换视图；`more-horizontal` 更多菜单（占位）。

- **行号开关**：标签栏行尾新增 `list-ordered` 按钮，点击切换编辑区源码左侧行号显示，与设置「显示行号」开关联动并持久化（ED-32）。

- **查找 / 替换条**：`Ctrl+F` 打开查找条、`Ctrl+R` 打开替换条（编辑器顶部工具条）：查找输入即时计数（当前/总数）、上一下一按钮跳转并高亮选中匹配；替换输入支持「替换当前」「全部替换」；`Esc` 关闭（ED-33 / ED-34）。

- **正文区**：

  - Markdown 渲染：H1/H2、段落、列表、待办、行内代码 / 加粗 / 链接；

  - 待办勾选：方框 / 对勾 / 删除线；代码块：`terminal` + 语言标 + 复制按钮 + 语法染色；

  - 引用块：左侧品牌色竖线 + 斜体正文；文章标签区：正文底部标签 chips。

- **状态栏**：已自动保存 + Markdown + UTF-8 + 行 / 列 + 字数 + 中文，随编辑变化。

- **真实数据与保存**：文件树、正文、元信息由 `noteStore` 真实数据渲染（替代硬编码）；正文为可编辑（所见即所得），`input` 事件实时计字数/更新状态栏，并**防抖自动保存**（约 800ms）写入磁盘（`notes:save`）；新建 / 删除笔记真实写盘（`notes:create` / `notes:delete`）；网页版无桥时降级为内存 mock。

### 2.3 右侧面板（侧边面板 280px）

- **面板头部**：标题「侧边面板」+「展开全部」`chevrons-down-up` +「关闭面板」`panel-right-close`。

- **大纲**：笔记标题结构列表，H1 高亮、子标题缩进，点击跳转对应标题；可折叠 / 展开。

- **反向链接**：引用当前笔记的其它笔记卡片（文件名 + 相对日期 + 正文预览 + 内链 `[[xx]]` 高亮）+ 计数徽标，点击卡片打开对应笔记。

- **标签云**：全部标签 chips + 计数徽标，字号 / 深浅体现热度，点击筛选（占位）。

- **宽度拖拽 / 持久化**：面板左缘拖拽条（`side-resizer`，桌面端）调整宽度（220–440px），宽度持久化到 `localStorage`（`settings.sideWidth`）；与左侧目录区（`treeWidth`）一起在启动时恢复上次宽度。

## 8. 数据层（笔记存储与 IPC）

> 全模块公共底座：编辑器 / 图谱 / 插件 / 设置的持久化统一走本层；桌面端用 Electron 真实文件系统，网页版降级为内存 mock。

### 8.1 笔记库位置与 seed

- **根目录**：`app.getPath('userData')/vault`（Electron 标准用户数据目录，不透传用户笔记到源码 / 打包产物）。

- **首次启动**：若 vault 为空，用内置 seed（把编辑器 / 图谱示例内容转成真实 `日记/2024年/09月/09-01.md` 等）写入，使图谱 / 编辑器开箱即有数据。

### 8.2 IPC 协议（主进程 `main.js`）

一组 `ipcMain.handle`，全部以**相对路径**为 key（拼接到 vault 后校验前缀，防路径穿越）：

| 通道 | 说明 |
| --- | --- |
| `notes:list` | 递归扫描 vault 内 `*.md`，返回 `[{path, name, folder, mtime, size}]` |
| `notes:read(path)` | 返回文件内容字符串 |
| `notes:save(path, content)` | 写文件（自动建父目录） |
| `notes:create(name)` | 在选定目录新建空 `.md`，返回完整相对路径 |
| `notes:delete(path)` | 删除文件（可回收则移入 trash） |

### 8.3 渲染层桥（`preload.js` → `js/app-*.js`）

- `preload.js` 在 `noteDesktop` 上暴露 `listNotes / readNote / saveNote / createNote / deleteNote`（内部 `ipcRenderer.invoke`），保留现有窗口控制。

- `js/app-note.js` 内 `noteStore` 模块（IIFE 内函数）：优先用 `window.noteDesktop`；网页版无桥时降级为**内存 mock**（内置示例库），保证 `start-server.bat` 调试仍可用；统一暴露 `list / read / save / create / remove` 供各视图调用。

第二脑此前为高保真演示版：正文不可编辑、文件树 / 状态栏 / 元信息为硬编码、图谱 / 插件 / 设置多处占位。目标为做成「可用编辑器闭环」：桌面端真实读写磁盘 `.md`，各视图交互补成真实逻辑；持久化采用 Electron 真实文件系统，网页版保留降级可用。

### 推进顺序

因编辑器与数据层是所有模块公共底座，依次推进：**数据层 + 编辑器闭环 → 图谱 → 插件市场 → 设置**，分块提交、逐块验收。

### 验收方法

- **桌面版（主形态）**：`cd second-brain; npm start`，实际新建 / 编辑 / 保存一条笔记 → 到 `userData/vault` 确认 `.md` 落盘 → 重启应用数据保留。
- **网页版降级**：`start-server.bat` → `http://127.0.0.1:8000/index.html` 仍可用（内存数据）。
- 浏览器实测关键交互 + 控制台无报错。
