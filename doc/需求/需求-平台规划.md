# 第二脑 · 需求文档：平台规划

> 跨视图的平台级能力规划：应用安全、加密插件、Git 同步。编号前缀 `SEC-` / `ENC-` / `GIT-`。

## 1. 应用安全

| 编号     | 功能点    | 说明                                          | 交互 / 数据                           |
| ------ | ------ | ------------------------------------------- | --------------------------------- |
| SEC-01 | 启动密码   | 首次启动时设置密码；每次打开应用需输入密码才能进入主界面                | 密码输入框 + 确认；密码本地加密存储（bcrypt 或等效方案） |
| SEC-02 | 超时锁定遮罩 | 应用长时间未操作（默认 10 分钟，可配置）后，弹出遮罩层，需重新输入密码才能继续使用 | 空闲计时器；遮罩覆盖全屏；密码正确则移除遮罩恢复原界面       |

## 2. 加密插件（待实现 · 示例插件）

| 编号     | 功能点     | 说明                                                                           | 交互                                     |
| ------ | ------- | ---------------------------------------------------------------------------- | -------------------------------------- |
| ENC-01 | 加密/解密文件 | 基于完善后的插件体系（PL-10/11/12），提供文件加密能力：右键菜单「加密此文件」、命令面板搜索「加密」、设置密码后对 .md 文件 AES 加密 | 右键菜单 / 命令面板触发；密码输入；加密后原文件变为密文格式；支持解密恢复 |

## 3. Git 同步

| 编号     | 功能点    | 说明                                                                     | 交互                      |
| ------ | ------ | ---------------------------------------------------------------------- | ----------------------- |
| GIT-01 | 初始化仓库  | 当前知识库一键 `git init`，自动将 .md 文件加入版本控制                                    | 设置页「同步与备份」分类 → Git 同步入口 |
| GIT-02 | 自动提交   | 笔记变更时自动执行 `git add . && git commit -m "auto: update YYYY-MM-DD HH:mm"` | 防抖提交，避免高频小提交            |
| GIT-03 | 远程仓库配置 | 配置远程仓库地址（https/ssh），支持多远程                                              | 设置页表单；保存时测试连接           |
| GIT-04 | 推送/拉取  | 手动或自动将本地变更推送到远程，支持从远程拉取最新内容                                            | 按钮操作；冲突时提示用户手动处理        |
| GIT-05 | 查看/还原版本（Git Sync 插件） | 不管理分支，仅管理**历史版本**：查看最近版本列表，可将工作区**还原到指定版本** | 命令面板「查看版本历史」「还原到版本…」；历史弹框列出版本并支持 Diff / 还原到此；还原用 `git checkout <hash> -- .` 覆盖工作区，不动 HEAD/历史指针 |
| GIT-06 | 同步到仓库（自动/手动） | 自动提交生成历史版本；「立即同步」提交并可推送到远程；自动推送为可配置开关（默认关，仅自动提交） | 命令面板「提交当前变更」「立即同步（提交+推送）」「自动提交: 开/关」；设置弹框配置间隔分钟与是否自动推送 |
| GIT-07 | 从 Git 打开知识库 | 输入仓库 URL，克隆为**独立知识库**并打开（不并入当前库） | 命令面板「从 Git 打开知识库…」→ host 选保存目录 → 克隆 → 注册并新开窗口 |
| GIT-08 | 宿主 Git 桥接（白名单） | main.js 新增 `git:run` / `git:check`、preload 暴露 `noteDesktop.git` / `cloneGit`；子命令白名单 + cwd 锁定当前知识库根，非 shell 执行规避注入 | 仅桌面版（渲染进程无 Node 权限，git 经 IPC 在主进程执行） |
| GIT-09 | 入口并联 | 命令面板 + 文件树右键 + 常驻状态条三处暴露 Git 全部能力，消除「只有 Ribbon」 | 命令面板命令；文件树右键合并插件菜单（file-tree/file-tree-folder slot）；右下/左下常驻状态条 |
| GIT-10 | 单文件历史/还原 | 文件树右键单篇笔记 → 直接弹该篇笔记历史弹框（左右布局：左列提交列表仅显示 hash+时间+「还原」按钮，点击列表在右侧展示该版本对比；右列顶部滑动开关切换「对比上一版本(关) / 对比本地文件(开)」，下方为 Diff 对比框；点击「还原」即还原该文件到对应版本）。互不影响库整体历史。右键菜单**不含**独立「还原此文件到版本」项；弹框加大 | 新增 `git-file-log` 命令 + file-tree 右键菜单；log 每次提交 → 左列条目；右列 diff：关=`diff <hash>^ <hash> -- <relPath>`、开=`diff <hash> -- <relPath>`；还原 → `checkout <hash> -- <relPath>`；host 右键时把目标路径暴露给插件（action 执行前恢复 __pluginCtxNote） |
| GIT-11 | 还原彻底性 | 还原到版本时**可选**清理该版本之后新增的未跟踪文件/空目录，保证工作区与版本完全一致 | 还原弹框复选；`git clean -fd`（host 白名单新增 clean，经 confirm + `--`） |
| GIT-12 | 历史改动文件 | 历史列表每条提交展示改动文件清单，可点某文件查看该次提交的具体 Diff | `git log --format=... --name-status`；清单点文件看 `git show <hash> -- <path>` 差异 |
| GIT-13 | 常驻 Git 状态指示 | 底部常驻状态条显示「分支 · 待提交数 · 是否未初始化」，点击可操作；周期+动作后刷新 | ~~插件注入左侧贴边 chip~~ **已取消**：左下贴边状态条遮挡目录区，状态反馈收敛到目录树状态着色（GIT-14，文件变动即时调色） |
| GIT-14 | 目录树状态着色 | 文件树按 Git 工作区状态着色（对齐 IntelliJ IDEA 深色）：新增(未跟踪)=红/橙、加入跟踪(暂存)=绿、修改=蓝、未变动=白；目录用宿主默认色，不单独着色；渲染即带状态色不闪烁 | `status --porcelain -z` → 全局映射 `window.__gsColoring` → 宿主渲染 `.tree-file` 时直接拼 class；插件更新映射并就地兜底补色 |
| GIT-15 | 过滤设置（编辑 .gitignore） | 自动提交忽略指定路径：Git Sync 设置弹框可编辑当前知识库 .gitignore，忽略路径不进自动提交 | 设置弹框「编辑 .gitignore」→ 读库根 .gitignore 到文本域、保存写回（notes:read/save）；git add . 天然尊重 .gitignore |
| GIT-16 | 实时提交 & Ribbon 同步 | ① 实时提交：文件变动即提交本地仓库（不等定时），关闭则不执行；② Ribbon 按钮改为同步：未初始化→确认后 git init，已初始化→提交到仓库 | 设置弹框「实时提交」开关；监听 #file-tree 重绘防抖触发静默 commitNow(false)；Ribbon actionKey=git-sync → syncNow（未初始化 confirm → initRepo；已初始化 → commitNow(autoPush)） |
| GIT-17 | 右键 Git 二级菜单 | 文件树右键笔记 → 二级菜单「Git」展开：对比、历史、回滚（放弃修改）、提交、拉取、推送 | host 右键菜单支持 children 二级菜单；manifest contextMenus.file-tree 声明父项 Git + 6 子项（gs-ctx-*）；子项 action 前恢复 __pluginCtxNote（作用于右键的那篇笔记）；对比=`diff HEAD -- <path>`、历史=fileLogModal、回滚=`checkout -- <path>`（确认）、提交=`add -- <path>`+commit、拉取=pull、推送=push；对比与历史弹框高度固定（gitsync-modal-lg height:76vh） |
| GIT-18 | 合并提交 & 空白区 Git 菜单 | ① 笔记右键 Git 新增「合并提交」：把该文件相对跟踪远端（origin/分支）的未推送改动压缩为一笔**仅含该文件**的提交；② 目录区**空白处**右键新增「Git」整仓菜单：提交 / 合并提交 / 拉取 / 推送（把当前分支所有未推送提交压缩为一笔）；③ **目录本身**右键新增「Git」菜单：提交 / 合并提交 / 推送，针对该目录下的文件 | 单文件=`reset <upstream>`(mixed，不动工作区)+`add -- <path>`+`commit`（其它文件改动降为工作区未暂存、内容不丢）；整仓=`reset --soft <upstream>`+`commit`（内容全保留、仅压缩历史）；目录=`reset <upstream>`(mixed)+`add -- <dir>`+`commit`（仅该目录进暂存，根目录用 `.`）；两者均需先配置跟踪远端分支（`rev-parse @{upstream}` 解析）；host `main.js` git 白名单新增 `reset` 并拦截 `--hard`；宿主空白区右键挂 `file-tree-blank`、目录右键挂 `file-tree-folder` slot 插件菜单（目录目标走 `__pluginCtxFolder`、可为根 `''`） |
| GIT-19 | 初始化创建默认过滤文件（.gitignore） | `git init` 初始化知识库时，库根若无 .gitignore 则自动写入**默认忽略规则**（过滤文件）：忽略应用内部数据 `.second-brain/` `.session/`、Obsidian 配置与回收站 `.obsidian/` `.trash/`、临时/日志文件 `*.tmp` `*.log`、操作系统文件 `.DS_Store` `Thumbs.db` `Desktop.ini`；已存在则保留用户自定义内容。**.resources/（上传的资源文件）需要版本管理，不忽略** | initRepo 在 `git init` 成功后读取库根 .gitignore（notes:read，不存在抛错）→ 不存在时写默认内容（notes:save，manifest 已有 vault.write 权限）；git add . 天然尊重 .gitignore，内部数据不进自动提交/历史 |
| RIB-01 | Ribbon 空白区右键二级菜单 | Ribbon 左侧**空白区**右键弹出**二级菜单**，一级含「Ribbon 最大显示个数」「开发人员工具」两个可展开项，hover/点击即在其右侧展开二级菜单 | 一级菜单项带右侧箭头；「Ribbon 最大显示个数」二级菜单 = 7~15 数值选项（当前值打勾）+ 恢复默认顺序（沿用 setMaxButtons/resetOrder）；「开发人员工具」二级菜单 = 打开/关闭开发者工具（`noteDesktop.toggleDevTools`，IPC → 主进程 `win:devtools` → webContents.toggleDevTools，浏览器版无 noteDesktop 则忽略）；外部点击关闭一级+二级 |
