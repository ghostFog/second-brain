# 第二脑 · 需求文档：命令面板

> 命令面板（command palette，`Ctrl+P / Cmd+P`）。编号前缀 `CMD-`，已用至 CMD-12。

| 编号     | 功能点     | 说明               | 交互 / 快捷键                  |
| ------ | ------- | ---------------- | ------------------------- |
| CMD-01 | 打开/关闭   | 遮罩 + 浮窗          | `Ctrl+P` 打开；`ESC` 或点击遮罩关闭 |
| CMD-02 | 命令搜索    | 占位“输入命令或搜索笔记...” | 输入实时过滤命令列表                |
| CMD-03 | 新建笔记    | 最近使用组            | `⌘N` / 选择执行               |
| CMD-04 | 打开笔记    | 最近使用组            | `⌘O` / 选择执行               |
| CMD-05 | 搜索笔记    | 文件操作组            | `⌘F` / 选择执行               |
| CMD-06 | 导出为 PDF | 文件操作组            | 选择执行                      |
| CMD-07 | 打开图谱视图  | 导航组              | `⌘G` / 选择执行，跳转图谱页         |
| CMD-08 | 浏览插件市场  | 插件组              | 选择执行，跳转插件页                |
| CMD-09 | 切换主题    | 插件组              | 选择执行（深/浅主题切换）             |
| CMD-10 | 同步设置    | 插件组              | 选择执行                      |
| CMD-11 | 键盘导航    | 上下选中、Enter 执行    | `↑↓` 导航、`↵` 选择、`esc` 关闭   |
| CMD-12 | 结果计数    | 底部状态栏（如 8 个结果）   | 随过滤更新                     |
