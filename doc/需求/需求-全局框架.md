# 第二脑 · 需求文档：全局框架

> 所有页面共享的全局能力。编号前缀 `G-`，已用至 G-12。

| 编号   | 功能点          | 说明                                  | 交互 / 数据                              |
| ---- | ------------ | ----------------------------------- | ------------------------------------ |
| G-01 | 标题栏库名        | 显示「我的笔记库」                           | 展示                                   |
| G-02 | 面包屑导航        | 如 日记/2024年/09月，末级高亮                 | 随当前笔记路径展示                            |
| G-03 | 命令面板入口       | 标题栏右侧「搜索 ⌘P」按钮                      | 点击或 `Ctrl+P/Cmd+P` 打开命令面板            |
| G-04 | 窗口控制         | 最小化 / 最大化 / 关闭（桌面版）                 | 自绘按钮，点击控制窗口                          |
| G-05 | Ribbon 导航    | 编辑器 / 搜索 / 图谱 / 插件 / 设置             | 点击切换视图；选中项高亮                         |
| G-08 | 笔记右键菜单       | 文件树笔记行右键                            | 在资源管理器中显示该笔记（桌面版）                    |
| G-09 | 库历史列表 / 拖拽调宽 | 库下拉框记录打开过的库、点击切换、悬浮 × 删除；目录区拖拽调宽    | 桌面版持久化到 settings.json / localStorage |
| G-06 | 同步状态点        | Ribbon 底部圆点                         | 显示同步状态（绿=已同步）                        |
| G-07 | 笔记库选择/切换     | 标题栏库名点击展开下拉框                        | 选择目录打开/切换库、恢复默认、持久化                  |
| G-10 | 迁移默认知识库      | 把默认知识库（userData/vault）内容迁移到用户选择的新目录 | 移动语义：选目录→二次确认→复制→清空原库→新目录成为默认库并持久化   |
| G-12 | 托盘托管          | 桌面版最小化后隐藏到系统托盘，任务栏不显示窗口，仅保留托盘图标    | **正常打开面板时窗口照常显示在任务栏**；最小化 / 缩小到托盘时才移出任务栏（setSkipTaskbar 动态切换）；托盘图标单击/双击恢复窗口；托盘右键菜单：显示主窗口 / 退出；应用图标统一（窗口/托盘/打包 exe 均为同一「脑」图标）；**关闭按钮(×)行为可配置**（设置页「常规」分类 → 关闭按钮行为）：每次询问（弹三选：退出程序 / 缩小到托盘 / 取消）/ 直接退出 / 缩小到托盘，持久化到 settings.json |
