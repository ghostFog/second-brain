## 4.2 vditor 引擎迁移（ED-42，2026-09-07）

> 放弃自研 Markdown 编辑引擎（源码 textarea + 自研 WYSIWYG + 自研预览），改用开源项目 vditor 整体替换编辑区。引擎进宿主 `js/editor/editor-vditor.js`（桌面 + 网页双端一致），`markdown-editor` 插件降级为「声明外壳」。宿主外壳（标签栏/文件树/侧边面板/状态栏/标题/索引面板）保留，三个模式按钮映射驱动 vditor。

| 编号    | 功能点       | 说明                                                         | 交互                                                   |

## 7. 图片/附件上传（ED-48，2026-09-11）

> 新增需求：Markdown Editor 编辑器支持上传「图片+附件（pdf、html、sh、bat、zip、doc、excel 等）」，上传的文件**落盘到知识库根级隐藏资源目录 `.resources`**，磁盘上用 **UUID 重命名**（保留扩展名），笔记内链接**使用真实文件名**（图片 `![真实名](note://vault_res/uuid.ext)`、附件 `[真实名](note://vault_res/uuid.ext)`）；`.resources` 目录 `.` 开头，**不出现在文件树**。附件点击用系统默认程序打开（不再整体导航窗口）。
>
> 交互增强（ED-48 扩展，2026-09-11）：支持 **拖拽文件到指定位置上传**（vditor 原生 drop→桩 `upload.handler`，落盘后在光标处插入）；**编辑区右键 →「插入图片」「上传附件」**（光标定位到鼠标处 + 文件选择 + 落盘 + 光标处插入；图片 `image/*` 插行内 `![名](url)`，附件非图片白名单插 `> [!attach]` 卡片引言）；新增 **Obsidian 风格附件语法 `> [!attach] 真实名 note://vault_res/uuid.ext`**：预览/阅读视图经 `preview.transform` 渲染成**附件卡片**（扩展名徽标 + 真实名 + 下载按钮，点卡片打开、右键「下载/复制链接」），编辑区把该引言渲染成**醒目附件指示块**（仅加 class 不改内容）；图片经 `note://` 协议在编辑/预览正常展示。网页版暂不支持（无桌面桥接时提示「上传仅桌面版支持」）。

## 8. Markdown Editor 插件增强化（ED-49，2026-09-12）
