# 第二脑 · 需求文档：AI 问答

> AI 问答视图（ai）全量功能点。编号前缀 `AI-`，已用至 AI-17。
> 设置侧（嵌入/重排序模型、生成模型列表等 ST-13~18）见 `需求-设置.md`。

| 编号    | 功能点      | 说明                                                                               | 交互 / 数据                                 |
| ----- | -------- | -------------------------------------------------------------------------------- | --------------------------------------- |
| AI-01 | 视图入口     | Ribbon 新增「AI 问答」（brain 图标）                                                       | 点击切换视图                                  |
| AI-02 | 知识库索引    | 将当前知识库全部 .md 切分并向量化（本地 ONNX 嵌入），索引按知识库名分文件存储，块携带元数据（知识库名/笔记 frontmatter id/块 id） | 首次进入/手动重建；展示索引状态（片段数）                   |
| AI-03 | 语义问答     | 输入问题 → 本地检索相关片段 → 远程/本地大模型流式回答                                                   | Enter 发送；SSE 流式显示                       |
| AI-04 | 回答来源     | 展示检索到的笔记片段（文件名 + 相似度 + 预览）                                                       | 点击片段打开对应笔记                              |
| AI-05 | 多轮会话     | 同一会话追问携带历史上下文                                                                    | 会话内消息累积                                 |
| AI-06 | 会话管理     | 新建会话 / 清空当前会话                                                                    | 按钮操作                                    |
| AI-08 | 模型选择器    | 底部输入区左侧下拉切换生成模型（值=模型 id，由顶部移入输入区）                                                | 下拉选择；切换即保存 currentModelId               |
| AI-09 | 多模型配置    | 支持配置多个生成模型（本地 Ollama / 远程 OpenAI 兼容）                                             | 设置页模型列表添加/编辑/删除；问答页底部切换                 |
| AI-10 | 会话侧栏     | 左侧边栏展示会话列表，支持多会话切换/删除与展开/收起                                                      | 点击切换会话；悬浮 × 删除；收起后左缘把手展开                |
| AI-11 | 索引增量更新   | 新建/保存/删除笔记自动触发该笔记块的增量索引更新，不影响库内其他笔记（按知识库名·笔记 frontmatter id·块 id 定位）             | 保存/删除笔记时后台触发                            |
| AI-12 | 查看索引     | 编辑区顶部「查看索引」按钮在编辑区底部内联展开当前笔记的分块索引（笔记 id / 块号 / 块 id / 文本片段）                       | 点击按钮展开/收起；切换笔记时随当前笔记刷新；无索引时提示去 AI 问答页重建 |
| AI-13 | 索引库管理    | AI 页顶部「重建索引」改为「索引库」下拉：列出所有已有索引的知识库；目录仍存在→显示「重建」，目录已移除但残留索引→显示「删除」；底部提供「重建当前知识库」  | 点击按钮开闭下拉；重建/删除行内操作并实时刷新                 |
| AI-14 | 嵌入模型自动检测 | 启动时自动检测本地常用模型管理器（Ollama / LM Studio）是否已下载嵌入模型                                    | 设置页/AI 页显示检测状态（已检测到 / 未检测到）             |
| AI-15 | 嵌入模型下载按钮 | 未检测到本地嵌入模型时，提供一键下载/拉取按钮（Ollama 走 `ollama pull`，其他管理器走对应命令）                       | 点击按钮执行下载；显示下载进度；完成后自动更新状态               |
| AI-16 | 语义分块        | 索引支持按语义拆分块：按段落 / 标题层级 / 语义完整句切分，而非固定字符数硬切                               | 设置页知识库索引提供切分策略选项：固定字符 / 语义分块；可与现有块大小/重叠配置共存 |
| AI-17 | AI 创建笔记     | AI 问答的回答支持一键保存为当前知识库笔记                                                   | 回答尾部「存为笔记」按钮 → 选择保存目录与文件名 → 写入 .md 并刷新文件树 |
