# 第二脑 · 需求文档：AI 问答

> AI 问答视图（ai）全量功能点。编号前缀 `AI-`，已用至 AI-22。
> 设置侧（嵌入/重排序模型、生成模型列表等 ST-13~18）见 `需求-设置.md`。

| 编号    | 功能点      | 说明                                                                               | 交互 / 数据                                 |
| ----- | -------- | -------------------------------------------------------------------------------- | --------------------------------------- |
| AI-01 | 视图入口     | Ribbon 新增「AI 问答」（brain 图标）                                                       | 点击切换视图                                  |
| AI-02 | 知识库索引    | 将当前知识库全部 .md 切分并向量化（本地 ONNX 嵌入），索引按知识库名分文件存储，块携带元数据（知识库名/笔记 frontmatter id/块 id） | 首次进入/手动重建；展示索引状态（片段数）                   |
| AI-03 | 语义问答     | 输入问题 → 本地检索相关片段 → 远程/本地大模型流式回答                                                   | Enter 发送；SSE 流式显示                       |
| AI-04 | 回答来源     | 展示检索到的笔记片段（文件名 + 相似度 + 预览）                                                       | 点击片段打开对应笔记                              |
| AI-05 | 多轮会话     | 同一会话追问携带历史上下文                                                                    | 会话内消息累积                                 |
| AI-06 | 会话管理     | 新建会话 / 清空当前会话                                                                    | 按钮操作                                    |
| AI-08 | 模型选择器    | 底部输入区左侧下拉切换生成模型（值=模型 id，由顶部移入输入区）                                                | 下拉选择；切换即保存 currentModelId               |
| AI-09 | 多模型配置    | 支持配置多个生成模型（本地 Ollama / 远程 OpenAI 兼容）                                             | 设置页模型列表添加/编辑/删除；问答页底部切换                 |
| AI-10 | 会话侧栏     | 左侧边栏展示会话列表，支持多会话切换/删除与展开/收起                                                      | 点击切换会话；悬浮 × 删除；收起后左缘把手展开                |
| AI-11 | 索引增量更新   | 新建/保存/删除笔记自动触发该笔记块的增量索引更新，不影响库内其他笔记（按知识库名·笔记 frontmatter id·块 id 定位）             | 保存/删除笔记时后台触发                            |
| AI-12 | 查看索引     | 编辑区顶部「查看索引」按钮在编辑区底部内联展开当前笔记的分块索引（笔记 id / 块号 / 块 id / 文本片段）                       | 点击按钮展开/收起；切换笔记时随当前笔记刷新；无索引时提示去 AI 问答页重建 |
| AI-13 | 索引库管理    | AI 页顶部「重建索引」改为「索引库」下拉：列出所有已有索引的知识库；目录仍存在→显示「重建」，目录已移除但残留索引→显示「删除」；底部提供「重建当前知识库」  | 点击按钮开闭下拉；重建/删除行内操作并实时刷新                 |
| AI-14 | 嵌入模型自动检测 | 启动时自动检测本地常用模型管理器（Ollama / LM Studio）是否已下载嵌入模型                                    | 设置页/AI 页显示检测状态（已检测到 / 未检测到）             |
| AI-15 | 嵌入模型下载按钮 | 未检测到本地嵌入模型时，提供一键下载/拉取按钮（Ollama 走 `ollama pull`，其他管理器走对应命令）                       | 点击按钮执行下载；显示下载进度；完成后自动更新状态               |
| AI-16 | 语义分块        | 索引支持按语义拆分块：按标题层级 / 段落 / 语义完整句切分，而非固定字符数硬切；语义块头注入「文件名+当前标题(含二级标题)」上下文；记录每篇笔记索引时间，文件更新后暴露过期状态          | 设置页知识库索引提供切分策略：固定字符 / 语义分块（语义分块忽略相邻重叠，单块上限仍生效）；可与现有块大小/重叠共存；支持单笔记级覆盖；「查看索引」面板对「索引时间早于文件修改时间」的笔记提示过期并提供「重建本篇」 |
| AI-17 | AI 创建笔记     | AI 问答的回答支持一键保存为当前知识库笔记                                                   | 回答尾部「存为笔记」按钮 → 选择保存目录与文件名 → 写入 .md 并刷新文件树 |
| AI-18 | 后台运行与恢复    | 切换 Ribbon 视图生成不中断，返回 AI 视图时保留进行中的回答气泡与已累计内容并继续流式输出                            | 切走/切回视图；生成中重进视图重建气泡并回灌 aiCurText              |
| AI-19 | 回答统计       | 每次回答记录并展示「使用模型 / 首 token 时长 / 总耗时 / **每秒 tokens（tok/s）**」；生成中顶部状态实时显示「生成中 · X.X tok/s」                                           | 气泡尾部统计行（tok/s = 累计 token 数 ÷ 生成耗时，onToken 每 chunk 计 1 token，节流 500ms 更新状态栏）；历史会话重绘仍显示                              |
| AI-20 | 生成打断       | 生成中提供「停止」，打断后保留已生成部分并标记「已打断」                                                 | 发送按钮生成中切换为「停止」；打断计入会话历史（带 stopped 标记）       |
| AI-21 | 可用模型过滤    | 底部模型选择器仅显示可用模型：本地 Ollama 仅展示正在运行（/api/ps）的模型，远程 OpenAI 模型始终可用                  | 引擎 listModels 按运行状态标记 running；前端过滤                    |
| AI-22 | 模型常驻       | 设置页「加载（常驻内存）」与 Ollama 问答请求均带 keep_alive=-1，模型常驻内存直到手动卸载，不再 5 分钟自动卸载；「启动常驻」开关（默认开）在应用启动时自动常驻最后使用的问答模型，加速首次问答           | 常驻（-1）/ 卸载（0）；问答请求不重置保活时长；启动常驻仅作用于当前问答模型（currentModelId），Ollama 服务未启动时静默跳过                    |
| AI-23 | 会话持久化     | 将 AI 会话（标题 + 完整消息历史）持久化到当前知识库根隐藏目录 `.session`：每会话一个 `<id>.json`，另存 `active.json` 记录最近活动会话；消息变更/标题变更/删除/切换即时落盘，应用启动时自动恢复会话列表并定位上次活动会话 | 按知识库各自 `.session` 隔离；文件树扫描自动跳过点开头目录；网页版（无桌面桥）降级为内存态不报错；会话 id 仅允许字母数字防路径穿越                    |
| AI-24 | 按组删除问答 | AI 问答对话区支持**按组删除**：一组 = 一次完整问答（1 条 user 提问 + 其后的 assistant 回答，含回答统计/来源气泡）。每组右上角 hover 显示「删除本组」按钮，点击删除该组全部消息并持久化重绘；删除生成中的组时先停止生成再删 | 消息渲染改为**问答组容器**（`.ai-qa-group`，`aiCurGroupEl` 跟踪当前组：user 开启新组、assistant 归入当前组）；`aiRemoveGroup(g)` 按 DOM 组序号定位 history 区间（该 user 起至下一 user 前）→ splice → 持久化 → 重绘；生成中删组先 `ai.stop()` 并复位生成状态（aiCurText 已清空，aiFinish 不会再写历史）；删除后空历史回空态引导；web 版（内存态）同效 |
