# 第二脑 · 需求文档：图谱视图

> 图谱视图（graph）全量功能点。编号前缀 `GR-`，已用至 GR-18。

## 1. 左侧过滤面板（220px）

| 编号    | 功能点    | 说明                        | 交互          |
| ----- | ------ | ------------------------- | ----------- |
| GR-01 | 标签过滤   | 勾选列表，圆点+名称+计数，头显“已选/总数”   | 勾选过滤图谱      |
| GR-02 | 连接深度   | 1层/2层/3层 + 滑块视觉 + `2层` 徽标 | 点击层数或拖动滑块调整 |
| GR-03 | 节点类型过滤 | 笔记 / 文件夹 / 标签，带图标+计数      | 勾选过滤节点      |
| GR-04 | 重置     | `rotate-ccw` 按钮           | 一键还原所有过滤条件  |

## 2. 顶部工具栏（40px）

| 编号    | 功能点  | 说明                         | 交互       |
| ----- | ---- | -------------------------- | -------- |
| GR-05 | 布局切换 | 力导向 / 层级                   | 点击切换布局算法 |
| GR-06 | 节点统计 | 节点 10 · 连接 14              | 展示       |
| GR-07 | 缩放控制 | `-` 缩小 / % / `+` 放大 / 重置视图 | 点击调整画布缩放 |

## 3. SVG 画布

| 编号    | 功能点  | 说明                             | 交互               |
| ----- | ---- | ------------------------------ | ---------------- |
| GR-08 | 节点展示 | 渐变节点（中心/普通/高亮）+ 名称标签，节点可带连接数徽标 | 展示，节点对应笔记/文件夹/标签 |
| GR-09 | 连线展示 | 一级粗线、二级弱线                      | 展示笔记间关联          |
| GR-10 | 脉冲动画 | 中心及侧节点放射波纹                     | 展示（装饰）           |
| GR-11 | 图例   | 左下角：当前节点 / 选中 / 普通节点 颜色示例      | 展示               |
| GR-12 | 操作提示 | 右下角「拖拽平移 · 滚轮缩放」               | 展示提示             |

## 4. 右侧节点详情面板（260px）

| 编号    | 功能点    | 说明                               | 交互            |
| ----- | ------ | -------------------------------- | ------------- |
| GR-13 | 面板标题   | 「节点详情」+ `info` 图标                | 展示            |
| GR-14 | 节点名称卡片 | 图标块 + 名称 + 分类徽标 + 连接数            | 展示选中节点        |
| GR-15 | 基本信息   | 创建时间 / 修改时间 / 字数                 | 展示            |
| GR-16 | 标签     | 节点标签 chips（带色圆点）                 | 展示            |
| GR-17 | 连接列表   | 关联节点列表，各带图标 + 连接方向箭头(入/出) + 计数徽标 | 点击列表项；hover 态 |
| GR-18 | 打开笔记   | 底部主按钮「打开笔记」`external-link`       | 点击打开对应笔记      |
