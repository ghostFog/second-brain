# 第二脑 · 需求文档：设置

> 设置（settings）全量功能点，含「设置 - AI 问答分类」。编号前缀 `ST-`，已用至 ST-32。

## 1. 分类侧边栏

| 编号    | 功能点  | 说明                                         | 交互         |
| ----- | ---- | ------------------------------------------ | ---------- |
| ST-01 | 分类导航 | 外观 / 编辑器 / 快捷键 / 同步与备份 / 隐私与安全 / 插件管理 / 关于 | 点击切换，选中态高亮 |
| ST-30 | 分类二级菜单 | 分类项可挂**二级子菜单**（缩进展示），点击子项直接定位到该分类对应设置区块；如「AI 问答 → 本地模型 / 生成模型 / 知识库索引」 | 点击子项：切换到所属分类并平滑滚动定位到对应区块，子项选中态高亮；点击主分类清除子项高亮 |
| ST-31 | 二级菜单折叠 | 含子菜单的分类项支持**展开/收起**二级菜单（分类项右侧箭头指示），默认收起 | 点击主分类：切换面板并同时展开/收起其子菜单（箭头随状态旋转）；点击子项自动确保其所属子菜单展开；切换到其他分类时收起已展开子菜单 |
| ST-32 | 生成模型运行状态刷新 | 「生成模型」区块支持按**刷新频率**自动刷新各组模型的**运行状态**（Ollama GET /api/ps），模型行的**加载/卸载按钮按运行状态显示**（运行中→卸载，未运行→加载）；组头提供**手动刷新**按钮；刷新频率可配置并持久化 | 默认刷新频率 10 秒；「添加模型」按钮左侧新增刷新频率输入（秒，持久化到配置）；每个 baseUrl 组按频率轮询 /api/ps，行内按钮随状态切换显示；组头「N 个模型」右侧加刷新按钮，点击手动刷新该组并反馈成功/失败 |

## 3. 关于面板（版本历史）

> 版本变更记录由应用内 `js/changelog.js`（全局 `window.CHANGELOG`，新→旧）维护；
> 打包发布时同步更新 `package.json` 的 version，并在 changelog 顶部追加新版本条目。

| 编号    | 功能点  | 说明                                         | 交互                   |
| ----- | ---- | ------------------------------------------ | -------------------- |
| ST-25 | 版本历史 | 展示各版本号、日期、版本标题与新增内容清单；页头版本号取自最新一条 | 「关于」面板时间线展示，超高时可滚动；打包发布时维护新版本 |

## 4. Web 设置

| 编号    | 功能点      | 说明                                      | 交互                      |
| ----- | -------- | --------------------------------------- | ----------------------- |
| ST-21 | Web 服务开关 | 开启/关闭内置 Web 服务（本地 HTTP 服务，复用 start-server 链路） | 开关控制；显示服务地址与端口；运行状态指示  |

## 5. 设置 - AI 问答分类

| 编号    | 功能点      | 说明                                                                               | 交互                  |
| ----- | -------- | -------------------------------------------------------------------------------- | ------------------- |
| ST-13 | 本地嵌入模型   | 配置向量化模型路径（默认 models/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2） | 输入路径                |
| ST-14 | 本地重排序模型  | 配置重排序模型路径（默认 models/bge-reranker-v2-m3）                                          | 输入路径                |
| ST-15 | 生成模型列表   | 列表展示已配置生成模型（供应商 + 模型名称 + 当前标记）                                                   | 添加/编辑/删除按钮          |
| ST-16 | 添加/编辑弹层  | 提供方 + 接口地址 + API Key + 模型名称                                                      | 弹层表单保存/取消           |
| ST-17 | 模型与服务状态  | 嵌入模型加载状态、索引状态                                                                    | 展示；重建索引按钮           |
| ST-18 | 模型下载目录设置 | 嵌入模型/重排序模型的下载存储目录可配置（默认随应用 models/ 目录）                                          | 目录选择器；修改后提示是否迁移已有模型 |
| ST-28 | 生成模型复制与拖拽排序 | 生成模型列表支持**复制**（克隆配置生成新 id 插入原项之后，方便快速派生同供应商/同接口模型）与**拖拽排序**（HTML5 原生拖拽，同步持久化顺序） | 行内复制按钮（copy 图标）；整行 draggable 拖拽；顺序落盘 |
| ST-29 | 生成模型 Ollama 管理与按地址分组 | ①添加/编辑模型时，Ollama 提供方可**从 Ollama 拉取模型列表**（GET /api/tags）直接选择；②Ollama 模型支持**加载/卸载**（keep_alive 控制常驻内存）与**上下文长度 num_ctx** 配置（随问答请求携带）；③生成模型列表**按 baseUrl（供应商地址）分组**展示，组头显示地址与模型数 | 弹层「获取模型列表」按钮→下拉选择；模型行内 加载/卸载 按钮 + num_ctx 输入；列表按地址分组渲染 |

## 6. 常规面板

| 编号    | 功能点      | 说明                                      | 交互                      |
| ----- | -------- | --------------------------------------- | ----------------------- |
| ST-26 | 关闭按钮行为 | 右上角 × 仅**首次**弹「关闭后希望执行什么操作？」并记住选择；之后按记住的选择直接执行，不再每次弹框，后续在设置-常规「关闭按钮行为」下拉维护（直接退出 / 缩小到托盘 / 每次询问） | 首次弹三选对话框；设置下拉切换，主进程持久化 |

## 7. 快捷键面板

> 快捷键分类由注册表 `js/app-keybinds.js` 驱动，命令及当前生效键位在「设置-快捷键」列表展示，支持「设置/清除/恢复默认」重绑。

| 编号 | 功能点 | 说明 | 交互 |
| ----- | ---- | ------------------------------------------ | ---------- |
| ST-27 | 内建快捷键：全屏 / 开发者工具 | 新增 `cmd:fullscreen`（默认 F11，切换整个应用窗口全屏，经 `win:fullscreen` IPC 调 `setFullScreen`）与 `cmd:devtools`（默认 F12，开/关开发者工具，经 `win:devtools` IPC）两条内置命令，纳入快捷键注册表，可在列表中查看与重绑 | F11/F12 或重绑键全局触发；编辑区内因功能键放行仍可触发 |
