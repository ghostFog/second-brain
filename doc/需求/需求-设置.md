# 第二脑 · 需求文档：设置

> 设置（settings）全量功能点，含「设置 - AI 问答分类」。编号前缀 `ST-`，已用至 ST-26。

## 1. 分类侧边栏

| 编号    | 功能点  | 说明                                         | 交互         |
| ----- | ---- | ------------------------------------------ | ---------- |
| ST-01 | 分类导航 | 外观 / 编辑器 / 快捷键 / 同步与备份 / 隐私与安全 / 插件管理 / 关于 | 点击切换，选中态高亮 |

## 2. 外观面板

| 编号    | 功能点  | 说明                                         | 交互                   |
| ----- | ---- | ------------------------------------------ | -------------------- |
| ST-02 | 主题模式 | 深色 / 浅色 / 跟随系统                             | 卡片选择，选中显示对勾          |
| ST-03 | 强调色  | 6 色圆点                                      | 点击切换主色调（紫/蓝/绿/橙/红/粉） |
| ST-04 | 字体大小 | 滑块 14–18px，默认 15px                         | 拖动调整正文字号             |
| ST-05 | 字体族  | Inter / Noto Sans SC / 系统默认                | 下拉选择                 |
| ST-06 | 代码字体 | JetBrains Mono / Fira Code / Cascadia Code | 下拉选择                 |
| ST-07 | 界面密度 | 紧凑 / 标准 / 舒适                               | 卡片选择，选中态高亮           |
| ST-08 | 显示行号 | toggle 开关                                  | 开关控制编辑区/代码块行号        |
| ST-09 | 自动换行 | toggle 开关                                  | 开关控制长文本折行显示          |
| ST-10 | 减少动画 | toggle 开关                                  | 开关降低界面过渡与动画强度        |

> 其余分类（编辑器、快捷键、同步与备份、隐私与安全、插件管理、AI 问答）：当前为导航入口，详细设置项随需求补充。

## 3. 关于面板（版本历史）

> 版本变更记录由应用内 `js/changelog.js`（全局 `window.CHANGELOG`，新→旧）维护；
> 打包发布时同步更新 `package.json` 的 version，并在 changelog 顶部追加新版本条目。

| 编号    | 功能点  | 说明                                         | 交互                   |
| ----- | ---- | ------------------------------------------ | -------------------- |
| ST-25 | 版本历史 | 展示各版本号、日期、版本标题与新增内容清单；页头版本号取自最新一条 | 「关于」面板时间线展示，超高时可滚动；打包发布时维护新版本 |

## 4. Web 设置

| 编号    | 功能点      | 说明                                      | 交互                      |
| ----- | -------- | --------------------------------------- | ----------------------- |
| ST-21 | Web 服务开关 | 开启/关闭内置 Web 服务（本地 HTTP 服务，复用 start-server 链路） | 开关控制；显示服务地址与端口；运行状态指示  |
| ST-22 | Web 服务选择  | 开启 Web 服务后选择当前使用的 AI 服务（本地/远程提供方）         | 下拉选择，与 AI 问答配置联动       |
| ST-23 | Web AI 问答 | Web 服务下支持 AI 问答（问答视图可用，能力与桌面版一致）          | 开启 Web 服务后 AI 问答视图可用 |

## 5. 设置 - AI 问答分类

| 编号    | 功能点      | 说明                                                                               | 交互                  |
| ----- | -------- | -------------------------------------------------------------------------------- | ------------------- |
| ST-13 | 本地嵌入模型   | 配置向量化模型路径（默认 models/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2） | 输入路径                |
| ST-14 | 本地重排序模型  | 配置重排序模型路径（默认 models/bge-reranker-v2-m3）                                          | 输入路径                |
| ST-15 | 生成模型列表   | 列表展示已配置生成模型（供应商 + 模型名称 + 当前标记）                                                   | 添加/编辑/删除按钮          |
| ST-16 | 添加/编辑弹层  | 提供方 + 接口地址 + API Key + 模型名称                                                      | 弹层表单保存/取消           |
| ST-17 | 模型与服务状态  | 嵌入模型加载状态、索引状态                                                                    | 展示；重建索引按钮           |
| ST-18 | 模型下载目录设置 | 嵌入模型/重排序模型的下载存储目录可配置（默认随应用 models/ 目录）                                           | 目录选择器；修改后提示是否迁移已有模型 |

## 6. 常规面板

| 编号    | 功能点      | 说明                                      | 交互                      |
| ----- | -------- | --------------------------------------- | ----------------------- |
| ST-26 | 关闭按钮行为 | 右上角 × 仅**首次**弹「关闭后希望执行什么操作？」并记住选择；之后按记住的选择直接执行，不再每次弹框，后续在设置-常规「关闭按钮行为」下拉维护（直接退出 / 缩小到托盘 / 每次询问） | 首次弹三选对话框；设置下拉切换，主进程持久化 |
