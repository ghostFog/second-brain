# 第二脑 · 需求文档：插件市场

> 插件市场（plugins）与插件体系能力。编号前缀 `PL-`，已用至 PL-20。

## 1. 头部与筛选

| 编号    | 功能点     | 说明                                      | 交互            |
| ----- | ------- | --------------------------------------- | ------------- |
| PL-01 | 页标题     | 插件市场 + 副标题                              | 展示            |
| PL-02 | 管理已安装插件 | `package-check` 按钮                      | 跳转已安装插件管理     |
| PL-03 | 搜索插件    | 占位“搜索插件...”                             | 按名称/描述过滤卡片    |
| PL-04 | 排序      | 最热门 / 最新 / 评分最高                         | 下拉切换排序        |
| PL-05 | 分类过滤    | 全部 / 编辑器增强 / 主题外观 / 数据同步 / 生产力工具 / 集成服务 | Chip 切换，选中态高亮 |

## 2. 插件卡片

| 编号    | 功能点   | 说明             | 交互            |
| ----- | ----- | -------------- | ------------- |
| PL-06 | 卡片信息  | 图标块、名称、作者、两行描述 | 展示            |
| PL-07 | 量化指标  | 下载量 + 评分       | 展示            |
| PL-08 | 安装/卸载 | 安装 或 已安装（可卸载）  | 点击安装；已安装态展示对勾 |

## 3. 详情抽屉与插件体系

| 编号    | 功能点        | 说明                                                          | 交互                                                         |
| ----- | ---------- | ----------------------------------------------------------- | ---------------------------------------------------------- |
| PL-09 | 详情抽屉       | 右侧滑出详情面板（默认折叠）                                              | 点击插件卡片展开详情（占位）                                             |
| PL-10 | 插件左侧图标注册   | 已安装插件可向左侧 Ribbon 栏注册自定义图标入口，点击切换到插件视图                       | 插件 manifest 声明 `ribbonIcon`；注册后与原生导航并列显示                   |
| PL-11 | 插件右键菜单注入   | 插件可向编辑器文件树、编辑区等位置注入自定义右键菜单项                                 | 插件 manifest 声明 `contextMenus`；与原生菜单合并显示                    |
| PL-12 | 插件被命令面板搜索到 | 已安装插件的命令（如「加密当前文件」）自动注册到命令面板，可被 Ctrl+P 搜索到                  | 插件 manifest 声明 `commands`；注册后出现在命令面板对应分组                   |
| PL-13 | 插件目录机制     | 插件为独立目录 `plugins/<id>/`（manifest.json + main.js），应用启动自动扫描加载 | 目录存在即已安装；main.js 经 `PluginAPI.register` 注册回调；目录插件优先于内置同名插件 |
| PL-14 | 编辑器能力插件化（md 操作独立） | 新增 **EditorProvider** 能力抽象：插件注册「支持文件后缀 + 打开方式 + 工具按钮 + 侧边面板」；核心宿主按后缀路由到 Provider，无匹配走内置纯文本兜底。md 的编辑器操作迁入独立插件 `plugins/markdown-editor/`（源码/所见即所得、预览、分屏、索引/侧栏操作均由该插件承接）；`renderMarkdown` 纯函数与 Tab/文件分发等通用宿主留在核心（AI 会话复用，不迁移） | 插件 manifest 支持 `editor` 能力字段（extensions/openers/toolbar/sidebar）；PluginAPI 暴露 `editor` 桥（getState/renderMarkdown/setMode/readNote/saveNote）与 `registerEditorProvider`；核心 `openNote(path,{mode})` 按后缀路由并应用默认打开方式；设置-编辑器新增「文件类型」映射表管理各后缀默认打开方式（`openAs:<ext>`）；文件树笔记右键首项改为「打开」二级子菜单（在资源管理器打开 + 各 Provider 打开方式） |
| PL-16 | 插件命令注册快捷键 | 插件命令可声明**默认快捷键**并支持用户在**设置-快捷键**重绑；内置命令与插件命令统一由快捷键注册表管理，支持冲突检测与恢复默认 | 插件 manifest `commands[]` 元素可声明可选 `shortcut`（默认快捷键）与 `keybindable`（默认 true）；启用插件时自动注册、停用/卸载时释放（默认键仅在无冲突时占用）；「设置-快捷键」动态列出内置+插件命令，支持设置/清除/恢复默认；命令面板快捷键展示取注册表生效键位（用户绑定 > 默认） |
| PL-18 | Minimal Theme 自定义配色 + 顶栏悬浮列表 | **Minimal Theme** 在 4 套内置配色（纸白/亚麻/冷灰/墨绿）基础上，支持**整套配色可调的自定义主题**；标题栏主题按钮**悬浮**时弹出可用主题列表下拉 | ① 自定义主题：插件设置新增 8 项 `color` 取色器（背景/卡片/表面/边框/主文字/次要文字/分隔线/强调色），套用时以 body 内联 CSS 变量写入并由插件派生完整变量集；`defaultTheme` 新增「自定义配色」选项；设置变更实时重套（正处于自定义主题时）。② 顶栏悬浮列表：鼠标悬停顶栏主题按钮弹出「停用/纸白/亚麻/冷灰/墨绿/自定义配色」下拉，点击应用并关闭；受「顶栏按钮悬停展示主题列表」开关控制，关闭后仅保留点击循环切换 |
| PL-19 | 插件版本号与配置同步 | 插件 manifest 声明**版本号**；在**设置-插件管理**中展示；检测到**新解压插件**或**版本号变化**时**同步所有配置** | 插件 manifest 的 `version` 字段即版本号；插件管理列表在行内展示「vX.Y.Z」徽标、基本信息中展示「插件版本」行列；`loadDirPlugins` 桌面启动扫描目录插件时，首次发现该插件（本地无 `plugin:<id>:__version__` 记录）或版本号与上次不同时，将 `settings` 中尚未保存的项补齐为默认值（不覆盖用户已有配置）并记录当前版本，便于下次比对升级 |
| PL-20 | 插件市场展示版本号 | 插件市场宣传卡片与**详情抽屉**展示插件的版本号 | 市场卡片标题行与详情抽屉头部在插件名后展示「vX.Y.Z」版本徽标；插件无 `version` 字段时不显示；内置市场数据为各插件补齐 `version` |

> 示例插件数据：Calendar(Kanban作者NoteApp Team)、Kanban(ProductivityLabs)、Excalidraw(Zsolt Viczián)、Git Sync(Vinadon)、Minimal Theme(Stephan Ango)、Mind Map(Vincent Le)、Notion Sync(Cloud Studio)、Code Highlight(Daniel W. P.)、Dark Mode Pro(hasegawa) 等，含分类 cat、下载量、评分。
