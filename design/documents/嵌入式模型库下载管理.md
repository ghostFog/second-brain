# 设置-AI问答-本地模型：下载目录管理 + 嵌入式模型库（4 模型从 HF/ModelScope 下载）

## Context（背景与目标）

当前「设置 → AI 问答 → 本地模型」区块只有两个手动路径输入框（`embedModelPath`、`rerankModelPath`）、自动加载开关和「加载嵌入模型」按钮。用户无法便捷地从公网拉取常用中文嵌入模型，且模型目录不固定（默认硬编码到工作区路径 `D:/BaiduSyncdisk/...`）。

目标：

1. 区块顶部新增「模型下载目录」设置，**默认值 = 应用数据目录** **`userData/models`**（`app.getPath('userData')` 下），可改/可打开。
2. 新增「嵌入式模型库」：默认给出 4 个模型，支持从 **HuggingFace / ModelScope（每个模型行内独立选源）** 下载到上述目录；本地已存在则该行显示已就绪。
3. 每个模型展示说明（CPU 速度 / 内存占用 / CPU 下实际表现 / 是否推荐 CPU 语义分块 / 推荐 cos 阈值），本地没有时显示「下载」按钮，点击从公网下载到设置目录。
4. 模型行内提供「使用」按钮：把该模型目录填入现有「嵌入模型路径」，供重新加载。

图见附件 af78635b/...（非本功能）；本功能参考现有生成模型的列表渲染与表单持久化模式。

## 关键决策（已与用户确认）

- 下载源：**每个模型行内独立下拉**选择 `HuggingFace` / `ModelScope`。

- 嵌入模型选择：**保留「嵌入模型路径」输入框**，模型行内加「使用」按钮填入该模型目录。

- 下载实现：**复用已装依赖** **`@xenova/transformers ^2.17.2`**（零新依赖），通过 `env.cacheDir` 落到下载目录、`env.remoteHost` 切源、`progress_callback` 推进度。ModelScope 拉取能力依赖该平台上同名 ONNX 镜像，性质为"尽力而为"，失败时引导改用 HF。

- 说明模型清单与阈值以用户给定表格为准（见下）。

## 实现步骤

### 1. 主进程（ai-engine.js）

- 在 `DEFAULT_CONFIG` 增加字段 `modelDir`，默认值在 run 时用 `app.getPath('userData')` 注入（改 `init()` 签名或新增 `setDefaultModelDir`）。注意 ai-engine.js 不直接 `require('electron')`，需由 main.js 传入 `userData` 路径（现 `initAiEngine` 已传 configFile/indexDir，可顺带传 `modelDir: path.join(userData,'models')`）。

- 新增方法：

  - `getModelLib()` 返回 `{ modelDir, models:[{repo, safename, local:boolean, size?}] }`：`safename = repo.replace('/', '_')`；`local` 通过 `fs.existsSync(path.join(modelDir, safename, 'onnx', 'model.onnx'))`（或 `model_quantized.onnx`）判断；若 `modelDir` 为空则回落到默认。

  - `setModelDir(dir)`：校验/创建目录，写回 `cfg.modelDir` 并 `saveConfig`。

  - `downloadModel(repo, source)`：动态 `import('@xenova/transformers')`，暂存原 `env` 状态；设
    `env.allowRemoteModels=true`、`env.allowLocalModels=false`（强制从远端拉）、`env.cacheDir=modelDir`、`env.remoteHost= (source==='modelscope' ? 'https://www.modelscope.cn' : 'https://huggingface.co')`；
    用 `pipeline('feature-extraction', repo, { quantized:false, progress_callback: cb })` 触发下载；恢复原 `env`；返回是否成功与错误信息。

  - `revealModelDir()`：`shell.openPath(modelDir)`（main.js 传 shell 或在此 `require('electron')` cautiously——ai-engine 在主进程，可 `require('electron').shell`）。

- 兼容性：下载用 `quantized:false` 与 `_loadEmbedder` 的 `{quantized:false}` 一致，确保 `onnx/model.onnx`(fp32)存在以便本地加载（Xenova 仓库两者都有）。

- 加载侧：不改 `_loadEmbedder`（仍 `localModelPath=dirname(embedModelPath)` + basename）。注意：用户点「使用」后 `embedModelPath=<modelDir>/<safename>`，其 `dirname=<modelDir>` 且 basename= safename，与缓存目录结构一致 → 本地可加载。

### 2. 主进程 IPC（main.js + preload.js）

- 新增 IPC 并转发到 aiEngine：

  - `ai:getModelLib` / `ai:setModelDir` / `ai:downloadModel` / `ai:revealModelDir`。

  - 下载进度经 `e.sender.send('ai:modelProgress', {repo, done, total, file})` 推送（参照现有 `ai:progress` 写法）。

- preload.js 在 `ai` 命名空间增加 `getModelLib()`、`setModelDir(dir)`、`downloadModel(repo, source, onProgress)`（内置 `onModelProgress` 回调替换）、`revealModelDir()`。

### 3. 渲染进程设置面板（app-settings.js）

- `settingsPanelHtml('AI 问答')` 的「本地模型」区块（约 92-104 行）重构为：

  1. 「模型下载目录」块：路径输入 `data-ai-cfg="modelDir"` + 「选择」按钮（弹窗/对话框选目录）+ 「打开」按钮；下方说明"默认：应用程序数据目录/models"。
  2. 「嵌入式模型库」区块：容器 `#ai-model-lib`；每模型一张卡片，含：模型名、状态点（已下载/未下载/下载中）、源下拉（HuggingFace/ModelScope）、「下载」按钮（下载中变进度条）、「使用」按钮、可展开的「说明」区（表格式信息）。
  3. 保留现有「自动加载」switch 与「加载嵌入模型」按钮（仍作用于 `embedModelPath`）。

- `bindAiSettings()` 扩展：

  - 用 `ai.getModelLib()` 填充模型库状态与目录输入；`collectLocal()/fillLocal()` 已按 `data-ai-cfg` 收集，`modelDir` 自然纳入（需同步 `DEFAULT_AI_FIELDS.modelDir` 做空占位）。

  - 源下拉切换保存到内存，下载时随 `downloadModel` 传入。

  - 下载按钮 → `ai.downloadModel(repo, source)`，`onModelProgress` 更新该行进度；完成后 `getModelLib()` 刷新 → 行转"已下载"。

  - 「使用」按钮 → `fillLocal({embedModelPath: modelDir + '/' + safename})` 并 Toast 提示重新加载。

  - 选项/源下拉/按钮事件需在每次渲染后重新绑定（按现有模式，或用事件委托）。

- 说明表格做成 toggle（点击模型名展开/收起），避免区块过挤；数据来自常量表。

### 4. 样式与图标

## 需在实现阶段运行时验证的点

- `@xenova/transformers` 在设 `cacheDir=modelDir` 后，实际落盘目录是否为 `modelDir/<safename>/...`（可能与 `${repo 处理}` 不同）。**先下载 bge-small-zh 一个小模型实测结构与加载**，若路径不符，把 `downloadModel` 的落盘/`_loadEmbedder` 的 `localModelPath` 对齐为实测结构。

- `env.remoteHost` 切到 ModelScope 是否可拉（尽力而为）：不可则 Toast 提示改 HF，不阻塞功能。

- 下载进度 `progress_callback` 字段（`{file, progress, loaded, total}`）时长验证以填充进度条。

## 验证（端到端）

1. `node --check` 校验 ai-engine.js / main.js / preload.js / app-settings.js 语法。
2. 打开桌面版 → 设置 → AI 问答 → 本地模型：

   - 目录默认显示 `.../userData/models`，可打开目录、可改目录并保存（重启后仍在）。

   - 4 个模型均显示「未下载+下载按钮」与独立源下拉；点击某模型「下载」（HF 源）→ 出现进度 → 完成后变为「已下载」。

   - 点击该模型「使用」→ 「嵌入模型路径」自动填入该模型目录 → 点「加载嵌入模型」成功（无“path not found”错误）。

   - 展开说明可见 5 项信息与阈值表。
3. 切换 source=ModelScope 测试下载，若平台不允许则该行为提示并回退 HF，不影响其余功能。
