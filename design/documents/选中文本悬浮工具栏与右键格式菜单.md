# ED-40 / ED-41：选中文本悬浮工具栏 + 右键格式菜单

## Context（背景与目标）

WYSIWYG 编辑区（`#ed-wysiwyg`）当前选中文本后格式能力分散在右键菜单，且只有加粗/斜体/删除线/下划线/高亮。需求文档已登记两项新需求：

- **ED-40 选中文本悬浮工具栏**：选中文本时上方弹出悬浮工具栏，提供字体/字号/颜色/背景色/斜体/加粗/下划线/删除线/段落/数学。
- **ED-41 选中文本右键格式菜单**：右键菜单提供与悬浮工具栏相同的格式项，与现有右键菜单合并。

二者**底层共用同一套作用于选中文本的格式动作**，仅触发形式不同。

**已确认决策**（用户拍板）：
1. 字体/字号/颜色/背景色「会话内可见」，且**保存回 markdown 做 HTML 透传持久化**（markdown 源保留 `<font>`/`<span style>`/`<u>`，渲染/往返不丢失）。
2. 「数学」=`$…$` 行内包裹，但按**行内块**处理：**整体选中 / 整体删除**。

## 核心难点：HTML 透传与数学内联块（改造渲染+序列化）

现状：`inline()`（`plugins/markdown-editor/common/md-render.js:22`）先 `esc(md)` 把 `<`、`>` 转义，任何内联 HTML 都变字面文本；`inlineToMd()`（`plugins/markdown-editor/common/md-serialize.js:16`）对 `u/span/font` 走 else 仅取 inner 文本，标签丢弃。因此不能直接支持透传或数学 span，需两处协同改：

**A. `inline()` 增加白名单内联 HTML 透传**
- 顺序：`internal(md)`；先对入参做白名单标签占位/还原——`esc(md)` 之后把 `&lt;/?(?:font|u|span)\b[^&]*&gt;` 还原回真实 `<…>`（仅白名单标签，防脚本注入），其余仍转义；随后的 `**`/`` ` ``/`[[ ]]`/`[ ]()` replace 照旧。
- 效果：用户 markdown 中的 `<font color=\"#ef4444\">红</font>`、`<u>下划线</u>`、`<span style=\"background-color:#ffe08a;\">高亮</span>` 在预览与 WYSIWYG 渲染时原样保留样式。
- 「数学」渲染：`inline()` 末尾再加 `.replace(/\\$([^$]+)\\$/g,'<span class=\"sb-math\" contenteditable=\"false\" data-math=\"1\">$1</span>')`——`$…$` 渲染为原子内联块（非可编辑，整体选中/删除的基础）。顺序放最前或最后均可，须在 esc 之后。

**B. `inlineToMd()`（`md-serialize.js`）对应序列化**
- 在元素分支新增：标签为 `font`、`u`，或 `span` 且带 `style` 的 → 输出 `node.outerHTML`（原样保留，与 inline 透传逐字一致，保证往返稳定）；文本内递归逻辑不变。
- `.sb-math`（`data-math`）span → 序列化为 `$` + inner 文本 + `$`（去掉包裹标签），与 `inline()` 的 `$…$`→span 往返一致。
- 其余 `strong/b→**`、`em/i→*`、`code→\`\``、`a→链接` 不变。

**C. 数学内联块的「整体选中/删除」**（`editor-host.js` 的 wys keydown）
- 复用现有 `#ed-wysiwyg` 的 Backspace/Delete 处理（Bug-022 之后的相邻块删除处）新增分支：光标紧邻（前一/后一兄弟）`.sb-math[data-math]` 时，Backspace/Delete 直接 `removeChild` 整块并 `dispatch input` → 整体删除。
- 点击 `.sb-math` → 标记 `edMathSel`（高亮类 `.sb-math.sel`）+ 光标移到块前；Backspace 再删整块 → 整体选中。
- 该分支放在现 `if (e.key==='Backspace' && …)` 之前，仅对 `.sb-math` 生效，不影响现有块逻辑。

## 架构（共享格式动作，两种触发）

共享格式定义为宿主全局，宿主 `js/editor/*` 由 `index.html` 同步先加载，插件 `new Function` 作用域可访问（同 `toggleSource`/`domToMd` 先例）：

```
js/editor/editor-format.js（新增，宿主+插件共享）
  ├── wysTextFmtGroup()   → 字体/字号/颜色/背景色/加粗/斜体/下划线/删除线/数学($包裹)/清除格式
  ├── wysParaFmtGroup(taskFn) → 各级标题/列表/正文/引用（taskFn 参数化任务列表动作）
  └── wrapWysInline(open, close)   → $ 数学行内包裹/解包
        ├── js/editor/editor-wys-toolbar.js（新增）→ 悬浮工具栏 ED-40
        ├── js/app-editor-ctx.js buildEdWysiwygSchema → 宿主右键菜单 ED-41/web
        └── plugins/markdown-editor/features/context.js buildEdWysiwygSchema → 插件右键菜单 ED-41/Electron
```

## 关键复用

- 格式应用：`execWys(cmd, value)`（`plugins/markdown-editor/common/md-helper.js:25`）＝`wys.focus()`+`document.execCommand`+`dispatch input`。字体/字号/颜色/背景色落地为 `<font face/color/size>`、`<span style="background-color:">`、`<u>`，由 A/B 透传往返。
- 右键菜单：`specItem(...)` + `children` 二级子菜单（`js/editor/editor-ctx.js` 的 `buildEdCtxItem`）。
- 悬浮浮层参照：`.mde-code-lang`（`md-helper.js` ensureCodeLangPicker/anchorCodeLangPicker：body 级+滚动 re-anchor+外部 mousedown 隐藏+按钮 mousedown stopPropagation）；`#wys-copy-btn`（`editor-host.js` bindWysCopyButton：fixed 浮层）。
- 原子块删除参照：现有`deleteWysBlock`/相邻块退格删块（Bug-022/024 逻辑），数学内联块复用同一思路。

## 文件改动清单

### 新增 A：`second-brain/js/editor/editor-format.js`
文件级注释，作者「火 冰」。常量 `WYS_FONTS`（宋体/黑体/微软雅黑/楷体/仿宋/Georgia/Consolas/Times New Roman）、`WYS_FONT_SIZES`（fontSize 2..6：小/正常/大/特大/超大）、`WYS_TEXT_COLORS` 与 `WYS_BG_COLORS`（12 色板：红#ef4444/橙#f97316/黄#f59e0b/绿#22c55e/青#06b6d4/蓝#3b82f6/紫#8b5cf6/粉#ec4899/灰#64748b/黑#111827/白#ffffff/浅青#99f6e4）。函数：
- `wysTextFmtGroup()` → `{label:'文本格式',icon:'type',children}`：加粗/斜体/下划线/删除线 → 分隔 → 字体/字号/颜色/背景色（各带 children 子菜单）→ 分隔 → 数学（`wrapWysInline('$','$')`）→ 清除格式。字面量 `{label,icon,action}` 构造。
- `wysParaFmtGroup(taskFn)` → 段落设置组：无序/有序/任务列表/引用 + `formatBlock` h1..h6/p。

### 新增 B：`second-brain/js/editor/editor-wys-toolbar.js`

## 测试与验证

2. 渲染往返：`$x$` → `inline()` 出 `.sb-math`，再 `inlineToMd` 回 `$x$`；`<font color="#ef4444">红</font>` 经 `inline()` 透传后 `inline()` 保留、`inlineToMd` 出 `<font color="#ef4444">红</font>`（stable）。
