# 项目信息（第二脑 / second-brain）

## 项目概览

- **项目名称**：第二脑（工程目录 `second-brain`）—— Obsidian 风格的笔记应用

- **形态**：桌面程序（Electron 主）+ 网页版（调试辅助）

- **技术栈**：Electron + 原生 HTML / CSS / Tailwind(本地化) / Lucide 图标 / hash 路由 SPA

- **设计基调**：单品牌色 Violet `#7C3AED`，深/浅双主题，Design Token 驱动

## 文档职责划分

- **`.hermes/`**：项目规则导览 + 编码规范；`design.md` / `progress.md` / `bug-tracking.md` 仅**协定规则与模板**（格式口径），不承载实际正文/数据，实际内容全部落地 `doc/`。

- **`doc/`**：设计与需求、进度、**项目结构**、历史 Bug 记录的落点与权威来源。

- **`doc/读取路由.md`**：AGENTS 启动后按「任务类型 / 模块」决定该读哪些文档的最小路径路由（节省 token）。

- **目录结构**：已独立成文，权威正文见 **`doc/项目结构.md`**（本文件不再承载结构正文，避免多处脱节）。
