# 设计与功能需求（变更前必查）

> **权威正文已迁至** **`doc/`**，本文件仅作重定向，不承载详情，避免两处脱节。

**核心规则：实现或修改任何功能前，必须先读以下文档 + 设计稿，再编码。**

## 必读文档

1. **视觉权威**：`doc/设计文档.md`（设计体系、各页布局与元素）。
2. **功能权威**：`doc/功能需求文档.md`（按页面枚举全部功能点，**不要遗漏**）。
3. **原始设计稿**：`design/pages/*.html`，共 5 页：
   `主编辑器.html`、`命令面板.html`、`图谱视图.html`、`插件市场.html`、`设置.html`。
4. **视觉规范（Design Token）**：`second-brain/css/base.css`。

## 变更前标准动作

1. 先读 `doc/功能需求文档.md` + `doc/设计文档.md` + 对应设计稿，明确视觉与交互目标、扫描是否有遗漏功能点。
2. 涉及文件变更：先展示改动前后对比，确认后再写入。
3. 实现后只测本次改动。
4. 改动如影响文档内容，同步更新 `doc/` 及 AGENTS.md 导航。
