# 开发进度

> **权威正文已迁至** **`doc/开发进度.md`**，本文件仅作重定向与格式示例。

## 必读

- 进度 / 待办 / 常用命令：一律读 `doc/开发进度.md`。

## 记录规则（表格示例）

- 每次完成一个功能的开发/修复后，在 `doc/开发进度.md` 对应模块表格新增/更新一行，并推进状态。

- 状态取值梯度：`计划` → `设计` → `编码` → `开发完成` → `测试完成` → `完成`。

- 若文档或目录结构发生增删改，同步核对 `AGENTS.md` 导航与 `.hermes/` 指向。

### 表格格式示例

每新增一个功能点，在 `doc/开发进度.md` 对应模块下追加一行，例如：

```
| 编号 | 功能点 | 功能点详情 | 状态 | 开始时间 | 完成时间 | 记录 |
| X-01 | 某某功能 | 功能说明/交互方式 | 计划 | 2026-09-02 | - | 新增功能点的备注 |
```

推进状态时，仅把「状态」一档、可填「完成时间」与「记录」。
